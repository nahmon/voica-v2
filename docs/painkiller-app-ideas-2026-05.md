## 1. Health & Wellness

### 1-1. RxBridge — 보험 사전 승인 자동화

**Problem**: 환자의 25%가 처방전 보험 사전승인(prior auth)에 3~14일 대기. 30%는 치료 자체를 포기.

**Solution**: 보험사 규칙 + 임상 데이터로 사전승인 요청서 자동 생성 → 보험사 직접 제출 → 실시간 추적.

**Why Now**: CMS의 전자 사전승인 API 의무화(2027) + TEFCA 기반 임상 데이터 연동 가능.

**Monetization**: 건당 $8-15 SaaS (약국/PBM 대상), 병원 엔터프라이즈 계약.

**Moat**: 보험사별 승인 로직 DB + 약국 파트너 통합 락인.

### 1-2. LabGap — 검사 결과 자동 해석기

**Problem**: 비정상 검사 결과의 40%가 의사에게 확인되지 않음. 환자는 PDF를 받아도 해석 불가.

**Solution**: FHIR로 환자 포털 연동 → 검사 결과 평문 해석 → 이상치 알림 → 다음 단계 추천.

**Why Now**: FHIR R4 환자용 API 연방 의무화 + LLM의 의료 데이터 그라운딩 정확도 향상.

**Monetization**: 소비자 $9/월 구독, DPC(직접진료) 병원 화이트라벨.

**Moat**: 의사 검증 기반 "안전 해석" 레이어 + 의료 책임 진입장벽.

### 1-3. NightWatch — 소아 발열 의사결정 엔진

**Problem**: 연 7천만 건 소아 ER 방문 중 80%가 불필요. 새벽 3시, 39.4°C — 부모는 기다려도 되는지 알 수 없음.

**Solution**: AAP 가이드라인 기반 소아 발열 트리아지. 나이·체온·증상 입력 → "대기/전화/응급실" 명확한 판정.

**Why Now**: LLM 트리아지 신뢰도 도달 + 코로나 이후 디지털 헬스 수용도 상승.

**Monetization**: 가족 구독 $4.99/월, B2B2C(소아과·보험사 — 불필요 ER 비용 절감).

**Moat**: AAP 가이드라인 라이선스 + 소아과 코브랜딩 신뢰.

### 1-4. ClearScript — 퇴원 안내문 번역기

**Problem**: 퇴원 안내문의 가독성 수준은 고교 2학년. 환자 50%가 이해 못 함 → 30일 내 재입원율 20%.

**Solution**: 퇴원 서류 촬영/EHR 연동 → 초등 수준 평문 재작성 → 복약 타이머 → 위험 증상 알림.

**Monetization**: 병원 대상 환자당 $15-40 SaaS (재입원 1건 방지 시 즉시 ROI).

**Moat**: Epic/Cerner 통합 스위칭 비용 + 재입원 감소 성과 데이터.

## 2. Personal Finance

### 2-1. FreelanceTax — 프리랜서 분기 세금 자동화

**Problem**: 6천만 프리랜서가 매 분기 예납세를 직접 계산. 잘못 내면 IRS 벌금.

**Solution**: Plaid 수입 자동 감지 → 예납세 계산 → 납부 리마인더 + IRS Direct Pay 연동.

**Why Now**: 긱 이코노미 성장 + IRS 1099-K 보고 기준 강화(2024~).

**Monetization**: 월 $15 구독 또는 세금 시즌 $49 원타임.

**Moat**: 세무사 제휴 네트워크 + 납부 이력 데이터.

### 2-2. SubKill — 구독 취소 대행

**Problem**: 평균 미국인은 구독 수를 실제보다 2.5배 적게 인식. 다크패턴 때문에 취소 불가 → 매달 수십 달러 누수.

**Solution**: 은행 계좌 연동 → 구독 자동 탐지 → 취소 절차 대행(전화 포함).

**Why Now**: FTC "Click-to-Cancel" 규제(2024) → 취소 프로세스 표준화 의무.

**Monetization**: 절감액의 20% 성과 수수료.

**Moat**: 수백 개 서비스 취소 절차 DB + 전화 대행 인프라.

### 2-3. RemitZero — 해외 송금 수수료 비교 & 타이밍 최적화

**Problem**: 이민자/해외 근로자의 송금 수수료 5~9% 숨김. 환율 최악 타이밍에 전송.

**Solution**: 실시간 수수료 비교(Wise, Remitly 등) + 환율 알림 + 최적 타이밍 자동 송금.

**Why Now**: Open Banking API 확산 + 송금 서비스 API 개방.

**Monetization**: 파트너 송금사 건당 레퍼럴 수수료.

**Moat**: 환율 예측 ML 모델 + 커뮤니티별 특화 루트 데이터.

### 2-4. RentShield — 보증금 분쟁 자동화

**Problem**: 미국 세입자 45%가 보증금 환급 실패. 소액재판 절차 복잡 → 대부분 포기.

**Solution**: 입주/퇴거 사진 타임스탬프 보관 → 법적 체크리스트 → 내용증명 자동 생성 → 소액재판 서류 보조.

**Why Now**: LLM 법률 문서 자동화 + 렌트 시장 경색으로 분쟁 급증.

**Monetization**: 분쟁 성공 시 회수액 15% 또는 월 $9 프리미엄.

**Moat**: 주(State)별 보증금법 DB + 판례 학습 모델.

## 3. Productivity & Work

### 3-1. MeetingTax — 회의 비용 가시화 & 집중시간 보호

**Problem**: 지식노동자가 하루 2~4시간을 안건·결정·후속 조치 없는 회의에 낭비.

**Solution**: 캘린더 연동 → 참석자 급여 기반 회의 실시간 비용 표시 → 액션 아이템 0건 회의 서피싱 → 자동 집중시간 블로킹.

**Why Now**: 리모트/하이브리드 회의 문화 폭발 → 기업의 시간 ROI 요구 급증.

**Monetization**: $12/user/월, HR·재무팀 대상 판매.

**Moat**: 급여 데이터 연동 + "회의 ROI" 벤치마크 축적.

### 3-2. ContextDrop — 컨텍스트 스위칭 제거 AI 사이드바

**Problem**: 개발자·디자이너가 하루 20~40회 Slack↔Jira↔Figma↔GitHub 전환. 매번 15~20분 컨텍스트 복원.

**Solution**: 로컬 AI가 현재 작업 감지 → 관련 Slack 스레드·Jira 티켓·문서를 검색 전에 자동 서피싱.

**Why Now**: LLM 시맨틱 매칭 실시간 가능 + 로컬 추론으로 엔터프라이즈 개인정보 해결.

**Monetization**: $18/user/월, 엔터프라이즈 우선.

**Moat**: 개인별 "컨텍스트 그래프" 학습 — 쓸수록 정확해짐.

### 3-3. ComplianceClip — 소기업 노동법 자동 업데이트

**Problem**: 1~50인 소기업에 HR 부서 없음. 최저임금·휴가·I-9 변경 놓치면 벌금 $1,000+.

**Solution**: 연방+주 노동법 변경 모니터링 → 정책 문서 자동 생성 → 마감 알림 + 직원 확인 추적.

**Why Now**: 2024-25년 미국 50개 주 임금/휴가법 변경 + AI 문서 생성으로 관할권별 맞춤화 저비용 가능.

**Monetization**: 25인 미만 $49/월, 100인 미만 $99/월.

**Moat**: 법률 변경 모니터링 데이터 + 관할권별 문서 템플릿.

### 3-4. OfferClose — 채용 오퍼 수락률 자동화

**Problem**: 구두 오퍼 → 서명까지 48-72시간 동안 후보자 이탈. 카운터오퍼·고스팅 발생.

**Solution**: 구두 오퍼 시점부터 구조화된 "클로징 시퀀스" — 자동 맞춤 터치포인트 + 후보자 감정 신호 + 카운터오퍼 대응 플레이북.

**Monetization**: 리크루터석 $299/월 또는 성과 기반 $500/채용.

**Moat**: 산업별 오퍼 수락률 벤치마크 데이터 + ATS 통합.

## 4. SMB & Commerce

### 4-1. ReturnShield — 소규모 셀러 반품 사기 탐지

**Problem**: Shopify/WooCommerce 소셀러 매출의 4~8%가 반품 사기(워드로빙, 빈박스). Riskified 같은 솔루션은 가격 초과.

**Solution**: 주문 이력 + 행동 신호 + 크로스 머천트 패턴으로 고위험 반품 사전 플래그 → 원클릭 분쟁 템플릿.

**Why Now**: Shopify 자체 반품 도구 부족 + LLM으로 소규모 패턴 매칭 비용 절감.

**Monetization**: $49-99/월 SaaS 또는 건당 수수료.

**Moat**: 크로스 머천트 사기 그래프 — 셀러 추가마다 데이터 복리.

### 4-2. SupplierPing — 수입업자용 공급업체 커뮤니케이션 허브

**Problem**: 아시아 수입 창업자가 주 3-6시간을 WhatsApp·WeChat·이메일·알리바바에서 공급업체 추적에 소비. 소통 실수 1건 = $10K+ 불량 재고.

**Solution**: 모든 채널 통합 인박스 + 자동 번역 + 핵심 약속(가격·리드타임·MOQ) 구조화 + 스마트 팔로업.

**Why Now**: LLM 비즈니스 번역 정확도 도달 + WeChat API 접근성 개선.

**Monetization**: 브랜드당 $79/월.

**Moat**: 공급업체 연락처 그래프 + 구조화된 스펙 이력.

### 4-3. TaxJurisdiction — $1M 미만 셀러 다주 판매세 자동 신고

**Problem**: Wayfair 판결 이후 소규모 멀티스테이트 셀러도 30개 주에 판매세 의무. TaxJar/Avalara는 $500-2,000/월로 비쌈. 무시하다 $40K 감사 통지.

**Solution**: Shopify/Amazon/Etsy 연동 → 넥서스 자동 계산 → 전체 주 신고서 작성·제출 → 새 넥서스 임계값 알림.

**Why Now**: 주정부 감사 강화 — $50K 임계값 셀러까지 대상 확대.

**Monetization**: 기본 $29/월 + 주당 $5.

**Moat**: 주별 신고 API 통합 선점.

### 4-4. ShiftFill — 당일 교대 근무 대체 매칭

**Problem**: 바리스타가 새벽 6시 결근 통보. 12명에게 문자 → 3명 회신 → 사장이 직접 투입. 매장당 월 2-4회 발생.

**Solution**: 내부 커버 실패 시 → 검증된 로컬 긱 워커 풀에 즉시 브로드캐스트 → 역할·경험·평점 필터 → 원탭 확정.

**Why Now**: 코로나 이후 긱 워커 공급 증가 + AI 역할 적합성 매칭 속도.

**Monetization**: 시급 15-20% 마크업, 구독 없이 사용 시 과금.

**Moat**: 하이퍼로컬 워커 평판 그래프 + 고용주 신뢰 점수 네트워크 효과.

## 5. Daily Life & Consumer

### 5-1. ParentTrack — 원격 부모님 건강 관리

**Problem**: 고령 부모와 떨어져 사는 40-60대. 낙상·복약 누락·응급 상황 실시간 파악 불가. 한국 65세+ 인구 900만 돌파.

**Solution**: 기존 스마트홈 센서 활용 + AI 생활 패턴 이상 탐지. "오늘 아침 냉장고 안 열었어요" 알림.

**Why Now**: Matter 프로토콜 표준화 → 설치 없이 기존 기기 활용.

**Monetization**: 가족 구독 ₩9,900/월 + 센서 번들.

**Moat**: 가족 네트워크 효과 + 생활 패턴 AI 학습 데이터.

### 5-2. ClaimFast — 보험 청구 자동화

**Problem**: 실손보험 청구 시 영수증 수집→앱/팩스→반려 반복. 건당 30-60분, 포기율 40%.

**Solution**: 영수증 사진 1장 → AI 서류 자동 완성 → 보험사 직접 제출 → 진행 상태 추적.

**Why Now**: 마이데이터 2.0 — 병원·보험사 API 의무 개방(2025~).

**Monetization**: 청구 성공 시 금액의 2-3% 수수료.

**Moat**: 보험사·병원 API 연동 계약 + 반려 패턴 학습.

### 5-3. MoveEasy — 이사 후 주소 변경 원스톱

**Problem**: 이사마다 평균 17곳에 개별 주소 변경. 누락 시 고지서 미수령→연체→신용 불이익. 한국 연 이사 800만+ 건.

**Solution**: 이사일·새 주소 1회 입력 → 연동 기관 자동 일괄 변경 → 완료/실패 대시보드.

**Why Now**: 행정안전부 공공 API 전면 개방 + 오픈뱅킹 의무화.

**Monetization**: 프리미엄 ₩14,900/건 + 이사 서비스 제휴 커미션.

**Moat**: 기관별 변경 프로세스 DB + 파트너십 진입장벽.

### 5-4. FixNow — 긴급 집 수리 신뢰 매칭

**Problem**: 주말 밤 수도 파열. 업체 찾아도 바가지·노쇼·자격 불명. 1인가구 급증으로 혼자 대처.

**Solution**: 인증 기사 실시간 매칭 + 출동 전 고정 요금 + 에스크로 결제 + 자격증·보험 DB 인증.

**Why Now**: 플랫폼 노동자 공급 증가 + GPS 정확도 + 소비자 피해 규제 강화.

**Monetization**: 거래 수수료 15% + 기사 월정액(우선 노출).

**Moat**: 인증 기사 공급망 + 긴급 상황 평점 데이터.
