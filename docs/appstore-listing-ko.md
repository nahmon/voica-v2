# App Store Listing - Korean (ko)

## App Name
시간아, 말해줘

## Subtitle (30 chars)
출발 전, 목소리로 알려드려요

## Promotional Text (170 chars)
외출 준비할 때 계속 시계 보지 않아도 돼요. 설정한 시간마다 목소리로 남은 시간을 알려드려요. 화장하면서, 짐 챙기면서, 손이 바쁠 때도 놓치지 마세요.

## Description

시간 보느라 준비가 늦은 적 있으신가요?

시간아, 말해줘는 외출 준비 중에 남은 시간을 목소리로 알려주는 앱이에요.
시계를 보지 않아도, 화장하다가 멈추지 않아도 됩니다.
5분, 10분, 15분 간격으로 설정하면 그때마다 목소리로 알림을 드려요.

─── 이런 분께 딱 맞아요 ───

• 출근 준비하다 매번 지각하는 분
• 화장·헤어할 때 시간 감각을 잃는 분
• 아이 등원 준비로 매일 아침이 전쟁인 분
• 손이 바빠서 폰을 자주 못 보는 분

─── 주요 기능 ───

🎙 목소리 선택
서연, 하린, 도윤, 멍멍이, 냐옹이 중에서 고르세요.
각자의 개성과 말투가 달라서 매번 달라요.

⏰ 외출 시간 설정
떠날 시간을 설정하면 앱이 남은 시간을 계산해 알려드려요.

🔁 알림 간격 조절
5분, 10분, 15분 중 원하는 간격으로 설정하세요.

💬 다양한 말투
격려, 유머, 카운트다운, 부드러운 안내 등 여러 스타일 중 선택하면
매 알림마다 랜덤으로 재생돼요.

🌐 한국어·영어 지원
앱 내 언어 전환으로 영어 음성과 UI도 지원해요.

─── 준비할 때만 켜세요 ───

타이머를 시작하면 백그라운드에서도 알림이 와요.
다른 앱을 쓰면서도 준비에만 집중할 수 있어요.
