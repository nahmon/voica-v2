## Summary

voicesurvey는 AI 음성 인터뷰 + 자동 분석 리포트라는 차별화된 가치를 제공하지만, **핵심 사용자 플로우에 블로커급 버그 3개**가 존재한다. 새 프로젝트 생성 후 `/editor/undefined`로 이동하는 버그, AI 질문 생성 401, Likert 질문 UI 완전 소멸이 그것이다. 이 세 개만 잡아도 실제 신규 사용자 이탈의 주요 원인이 제거된다. 리포트 화면 자체는 데이터가 있을 때 임팩트가 강하다.

## Findings

### Critical

#### C-01. 새 프로젝트 → `/editor/undefined` 이동
**재현:** 대시보드 → `+ 새 프로젝트` 클릭  
**증상:** URL이 `/editor/undefined`로 이동. Supabase 쿼리 `id=eq.undefined` → 400 에러.  
**원인 추정:** 프로젝트 생성 API 응답을 기다리지 않고 `navigate('/editor/' + project?.id)` 호출 → `project`가 아직 `undefined`.  
**영향:** 새 프로젝트에서 저장 불가, AI 생성 불가, 링크 복사 불가. 신규 사용자 첫 경험이 완전히 망가짐.  
**Screenshot:** `02-new-project-bug.png`

**Fix:** 프로젝트 생성 await 후 navigate. 생성 실패 시 에러 토스트.
```js
// 현재 (추정)
createProject(data);
navigate(`/editor/${project?.id}`);

// 수정
const project = await createProject(data);
if (!project?.id) throw new Error('생성 실패');
navigate(`/editor/${project.id}`);
```

#### C-02. Likert(평가 척도) 질문에서 입력 UI 사라짐
**재현:** 참여자 인터뷰 링크 접속 → 등록 → 인터뷰 시작 → Q3(평가 척도) 도달  
**증상:** 질문 텍스트는 보이지만 1–5 평가 버튼, 음성 녹음 버튼 등 모든 인터랙션 요소가 DOM에 없음. `나가기` 버튼만 존재. 진행 불가.  
**영향:** 인터뷰 도중 평가 척도 질문을 만나면 완전히 막힘. VCS-005 기준 완료율 23%의 원인일 가능성 높음.  
**DOM 확인:** `document.querySelectorAll('button')` → `["나가기"]`만 반환.

**Fix:** `InterviewScreen`에서 `type === 'likert'` 케이스의 렌더링 경로 확인. 오디오 로드 상태와 관계없이 UI가 노출되어야 함.

---

#### C-03. `funnel_events` 403 에러 — 이벤트 트래킹 전무
**재현:** 참여자 인터뷰 진행 중 콘솔 모니터링  
**증상:** 매 인터랙션마다 `POST /rest/v1/funnel_events → 403`. 7회 이상 반복.  
**원인:** Supabase RLS(Row Level Security) 정책이 `funnel_events` 테이블에서 INSERT를 차단하거나, anon key에 권한이 없음.  
**영향:** 퍼널 분석 데이터 전혀 수집 안 됨. 사용자 행동 데이터 손실. 제품 개선의 근거가 없음.

**Fix:** Supabase 대시보드 → `funnel_events` 테이블 → RLS 정책 추가:
```sql
CREATE POLICY "allow_insert_funnel_events" ON funnel_events
  FOR INSERT WITH CHECK (true);
```

### High

#### H-01. AI 질문 생성 `/api/generate-questions` → 401
**재현:** 에디터 → `AI로 인터뷰 쉽게 만들기` → 텍스트 입력 → `초안 생성`  
**증상:** `POST /api/generate-questions → 401`.  
**원인 추정:** API 호출 시 `Authorization: Bearer <token>` 헤더가 빠져 있거나, Vercel 환경변수 `OPENAI_API_KEY` 미설정.  
**영향:** 핵심 차별화 기능 완전 불능. 신규 사용자가 처음 시도하는 기능.

**Fix:** 클라이언트 코드에서 AI 생성 fetch에 토큰 헤더 추가:
```js
headers: {
  'Authorization': `Bearer ${session.access_token}`,
  'Content-Type': 'application/json'
}
```

---

#### H-02. 질문 10개 제한 미차단 — `11/10` 표시 후 저장 허용
**재현:** VCS-001 에디터 열기  
**증상:** 헤더에 `11/10` 표시되나 저장 버튼 활성화, 저장 가능.  
**영향:** 제한 정책이 UI만 있고 실제 검증 없음. 유료 플랜 차별화에 구멍.

**Fix:** 저장 시 서버/클라이언트 양쪽에서 질문 수 검증. `questions.length > limit` 시 저장 버튼 비활성화 + 토스트.

---

#### H-03. 리포트 섹션 번호 불연속 (04, 08 누락)
**재현:** 구 리포트 데이터로 생성된 리포트 열람  
**증상:** 01 → 02 → 03 → **05** → 06 → 07 → **09**. 04(문항별 AI 인사이트), 08(인구통계 인사이트)가 없는 리포트에서 번호가 점프.  
**원인:** 새 `Section` 컴포넌트 도입 시 구 데이터(`questionInsights`, `demographicInsights` 필드 없음)에 대한 fallback 처리 없음.  
**영향:** 처음 보는 사용자가 "04가 왜 없지?" 혼란. 신뢰감 하락.

**Fix:** 섹션 번호를 하드코딩 대신 렌더링 순서 기반으로 자동 부여. 또는 데이터 없는 섹션은 번호 스킵 대신 "데이터 없음" 상태 표시.

---

#### H-04. 응답 화면 i18n 미적용
**재현:** 대시보드 → 프로젝트 → 응답 보기  
**증상:** `← Dashboard`, `Export CSV`, `View report`, `Multiple choice`, `Voice`, `Rating`, `No response`, `Compact view`, `Respondents (N)`, `In progress` 등 영어.  
**영향:** 한국어 메인 타겟 사용자에게 일관성 없는 경험.

### Medium

#### M-01. 링크 복사 후 피드백 없음
**재현:** 에디터 → `링크 복사` 버튼 클릭  
**증상:** 클릭 후 아무 피드백 없음. 토스트, 버튼 상태 변화 없음.  
**영향:** "복사됐나?" 불안. 여러 번 누름.

**Fix:** 클릭 후 300ms 동안 버튼 텍스트 "✓ 복사됨" 또는 토스트.

---

#### M-02. 닉네임 placeholder "예: coffee-saving-desk" 혼란
**재현:** 참여자 인터뷰 링크 접속 → 등록 화면  
**증상:** 닉네임 필드 placeholder가 랜덤 slug 형식. 일반 사용자는 "내 이름을 쓰면 되나?" 혼란.  
**Fix:** placeholder를 "예: 홍길동" 또는 "이름 또는 닉네임"으로 변경.

---

#### M-03. 프로젝트 행 전체 클릭 → 에디터로 이동 (응답 보기 어려움)
**재현:** 대시보드 → 프로젝트 행 클릭  
**증상:** 행 전체가 에디터(`/editor/...`)로 이동. `응답 보기` 버튼 영역이 좁아 클릭하기 어려움.  
**영향:** 응답 확인을 주로 하는 리서처가 계속 에디터로 튕겨남.

**Fix:** 응답 있는 프로젝트의 기본 클릭 동작을 응답 보기로 변경하거나, 버튼 클릭 영역 명확히 분리(event.stopPropagation).

---

#### M-04. 웹폰트 로딩 지연
**증상:** Playwright에서 스크린샷 시 `waiting for fonts to load...` 5초 이상 대기 후 타임아웃.  
**영향:** 실제 사용자도 초기 FOUT(Flash of Unstyled Text) 또는 렌더 블로킹 경험 가능.  
**Fix:** `font-display: swap` 추가. 중요 폰트는 `<link rel="preload">`.

---

### What Works Well

- **인터뷰 참여자 UI:** 진행률(1/11), 타이머(~6분 남음), "답변은 암호화되어 안전하게 저장됩니다" 메시지가 신뢰감 형성.
- **이전 답변 표시:** 인터뷰 중 이전 Q/A가 채팅 버블로 표시 — 문맥 유지 excellent.
- **마이크 확인 건너뛰기:** 선택적 온보딩 step. 마찰 최소화.
- **리포트 정량 결과:** 객관식 바 차트 렌더링이 데이터 있을 때 시각적으로 강함.
- **GNB 로고 → 랜딩 페이지 이동:** 정상 작동.
- **2단계 온보딩 (등록 → 마이크 확인):** 단계 명확, 건너뛰기 옵션 있어 양호.
