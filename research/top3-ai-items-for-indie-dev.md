## Top 3 딥다이브

### 🥇 1위: AI 한국어 글쓰기 코칭 플랫폼 (21점)

**선정 이유 (스코어 분석):**
- **Solo Dev 4점**: LLM API 호출 + 맞춤법 검사 API 조합으로 MVP 구현 가능, 자체 모델 학습 불필요
- **MVP 속도 5점**: 웹 프론트엔드 + API 래핑만으로 핵심 기능 완성, 커스텀 데이터 불필요
- **수익화 5점**: 낮은 가격(월 9,900원), 즉각적 가치 체감, 셀프서브 결제로 출시 즉시 과금 가능
- **기술 리스크 5점**: 텍스트 교정/코칭은 가장 검증된 LLM 유스케이스
- **경쟁 해자 2점**: GPT 래퍼 수준의 진입장벽으로 차별화 유지 어려움 (유일한 약점)

**왜 1위인가:**
- 바른한글 월 200만+ 방문 → 기존 수요 검증 완료
- "한국어 Grammarly"가 아직 부재 (글로벌 서비스의 한국어 지원 미흡)
- 취준생(자소서), 직장인(보고서), 블로거(SEO) 등 페르소나 다양
- 해자는 약하나 **실행 속도로 선점** 가능

**프로덕트 구상:**
```
[무료] 맞춤법 검사 + 글자수 세기 (트래픽 확보, SEO)
[프리미엄 월 9,900원] AI 문체 교정 + 자소서 코칭 + 가독성 분석
[B2B] 기업용 사내 문서 품질 관리 API
```

**기술 스택:** Claude/GPT API + 바른한글 맞춤법 엔진 연동 + Next.js
**예상 초기 MRR:** 수천만 원 (취준생 시장 규모 기준)

### 🥈 2위: AI PDF/HWP 변환 + 문서 요약 플랫폼 (20점)

**선정 이유 (스코어 분석):**
- **Solo Dev 4점**: LLM 요약은 API 호출로 해결, HWP 파싱은 오픈소스(hwp5) 활용 가능
- **MVP 속도 4점**: LLM 요약은 빠르나 HWP 파서 안정화가 변수, 오픈소스 활용 시 1-2개월
- **수익화 5점**: 기존 67만 트래픽 풀에 프리미엄 업셀, 도구형이라 체험→결제 전환 빠름
- **기술 리스크 3점**: HWP는 비공개 바이너리 포맷으로 파서 안정성 확보 까다로움
- **경쟁 해자 4점**: HWP는 한국 고유 포맷, 글로벌 경쟁자(iLovePDF 등)가 진입할 유인 없음

**왜 2위인가:**
- HWP 변환은 한국 정부/학교/군대의 필수 수요 → 줄지 않음
- Allinpdf 월 67만 방문으로 시장 검증 완료
- **구조적 해자**: 글로벌 서비스가 HWP를 지원하지 않음 (한국 고유 블루오션)
- AI 문서 요약/Q&A 결합 시 "변환 도구" → "문서 인텔리전스 플랫폼"으로 진화

**프로덕트 구상:**
```
[무료] HWP→PDF/Word 변환 + 기본 OCR (SEO 트래픽 확보)
[프리미엄 월 9,900원] AI 문서 요약, AI 문서 Q&A, 배치 변환, API
[B2B] 정부/기업용 대량 HWP 변환 + 문서 아카이빙 AI
```

**기술 스택:** HWP 파서(hwp5/자체) + Claude API + RAG(문서 Q&A) + Next.js
**예상 수익:** 프리미엄 전환율 3% × 67만 방문 × 9,900원 = MRR 2억 원+ 가능

### 🥉 3위: AI 세무/재무 상담 챗봇 (16점)

**선정 이유 (스코어 분석):**
- **Solo Dev 3점**: RAG + LLM 구현은 가능하나 세법 정확도 검증에 도메인 전문성 필요
- **MVP 속도 3점**: 세법 RAG 데이터 수집·검증 필요, 정확도 QA 기간 소요
- **수익화 4점**: 건당 과금 모델로 즉시 수익화 가능, 다만 시즌 편중(1-3월)과 규제 리스크
- **기술 리스크 2점**: Hallucination → 법적 책임 직결, 정확도 보장 극히 어려움 (최대 약점)
- **경쟁 해자 4점**: 매년 변경되는 세법 큐레이션 + 규제 준수 + 브랜드 신뢰가 복합적 진입장벽

**왜 3위인가:**
- 계산기 사이트 10개+ 합산 트래픽 월 수백만 → 수요 검증 완료
- "연봉 실수령액" 매년 1-3월 폭발적 검색량 (시즈널 트래픽)
- 세무사 상담 비용(10-30만 원)을 AI로 대체 → 명확한 가치 제안
- **경쟁 해자가 가장 강함**: 도메인 지식 + 규제 준수가 자연적 진입장벽
- 기술 리스크(hallucination)를 "AI 참고용, 세무사 최종 확인 권장" 면책으로 완화 가능

**프로덕트 구상:**
```
[무료] 기존 계산기 기능 (연봉 실수령액, 퇴직금, 세금 — SEO 트래픽)
[프리미엄 월 9,900원] AI 세무 상담 ("절세하려면 어떻게?")
[B2B] 세무법인 고객 응대 AI 어시스턴트
```

**기술 스택:** LLM + 한국 세법 RAG + 국세청 API 연동 + Next.js
**예상 수익:** 상담 건당 5,000-10,000원 + 세무법인 B2B 월 구독

## 전략적 시사점

### Top 3 공통 패턴
1. **무료 도구로 SEO 트래픽 확보** → AI 프리미엄으로 전환 (freemium)
2. **한국 고유 pain point 타겟** → 글로벌 서비스가 커버 못하는 영역
3. **LLM API 호출 중심** → 자체 모델 학습 없이 빠른 MVP 가능

### 실행 우선순위 제안
| 순서 | 아이템 | 이유 |
|------|--------|------|
| 1st | AI 글쓰기 코칭 | MVP 가장 빠름, 기술 리스크 최저, 즉시 수익화 |
| 2nd | AI HWP 변환+요약 | 해자 가장 강함, 기존 트래픽 활용 가능 |
| 3rd | AI 세무 상담 | 해자 강하나 기술 리스크(정확도)가 높아 후순위 |

### 탈락 아이템 요약
- **AI 적응형 타자 연습**: 만들기 쉽지만 돈이 안 됨 (수익화 1점, 해자 1점)
- **AI 코딩 튜터**: ChatGPT/Cursor 등 무료 대안이 너무 많음
- **AI 커머스 상품사진**: 수익화는 좋으나 Photoroom/remove.bg 등 글로벌 경쟁 치열
- **AI 부동산 예측**: ML 전문성 + 데이터 파이프라인 → 1인 개발 비현실적
- **AI 스포츠 예측**: 예측 정확도 본질적 한계 + 도박 규제 리스크
