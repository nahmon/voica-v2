# 성경 기반 꿈해몽 AI 서비스 — 사업 타당성 분석

> 2026-04-15 | 5-Agent Team Research

## Executive Summary

**서비스 컨셉:** 사용자가 꿈을 텍스트로 입력하면, AI가 성경 구절과 신학적 원리에 기반하여 꿈의 의미를 해석해주는 서비스

### 핵심 발견

| 항목 | 결론 |
|------|------|
| **시장 공백** | 한국어 + 성경 기반 + AI 꿈해몽을 동시 충족하는 서비스 **0개** |
| **TAM** | 한국 영적 웰니스 앱 시장 약 4,200~5,600억 원 |
| **SOM (3년)** | 52~87억 원 (MAU 15~25만 명) |
| **BEP** | 유료 구독자 146~233명 (월 4,900원 기준) |
| **기술 난이도** | 기존 voica-v2 스택 100% 재사용, 새 패키지 불필요 |
| **MVP 비용** | 월 $15~25 (API 비용, 일 100건 기준) |
| **선례** | Bible Chat: MAU 1,000만, 연매출 $15M, App Store 전체 13위 |

### 왜 지금인가?

1. **검증된 수요**: 한국 점술 시장 1.4조 원, 점신 앱 1,900만 사용자 — 기독교인도 30%가 점술 경험
2. **기독교 AI 붐**: Bible Chat $14M 시리즈A, Hallow 가톨릭 앱 $9.99/월 성공
3. **기술 성숙**: GPT-4o가 성경 지식 내장, RAG 없이도 MVP 가능
4. **3중 공백**: 한국어 × 성경 기반 × AI — 이 교집합에 경쟁자 제로

### 핵심 리스크

| 리스크 | 완화 전략 |
|--------|----------|
| 신학적 논란 | "꿈해몽" 대신 "성경으로 꿈 돌아보기"로 포지셔닝 |
| 보수 교단 반발 | 면책 고지 + 신학 자문단 구성 |
| 점술로 오인 | AI 응답에 성경 구절 필수 인용 + "예언이 아닌 묵상 가이드" 명시 |
| 고령 사용자층 | 카카오톡 채널 우선, 앱은 2차 |

### 권장 실행 계획

| 주차 | 마일스톤 |
|------|----------|
| 1~2주 | MVP 개발 (단일 API + 랜딩페이지) |
| 3~4주 | 베타 테스트 (교회 소그룹 50명) |
| 5~6주 | 정식 런칭 + 카카오 채널 오픈 |
| 7~12주 | 유료 전환 + 교회 B2B 플랜 |

## 결론: GO / NO-GO

**GO** — 다음 근거:

1. 시장 공백이 명확하고 검증 가능한 선례(Bible Chat, 점신)가 존재
2. 기존 기술 스택으로 2주 내 MVP 가능, 추가 비용 최소
3. BEP가 146명으로 매우 낮아 리스크 제한적
4. "성경 묵상 가이드" 포지셔닝으로 신학적 리스크 관리 가능
5. 실패해도 매몰 비용이 거의 없음 (인디 개발자 시간 + 월 $25 API 비용)
