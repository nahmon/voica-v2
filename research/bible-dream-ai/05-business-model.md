### 2-2. 채택 모델: Freemium + 구독

```
[무료 티어] — 획득(Acquisition) 엔진
  · 꿈 해석 월 3회 무료
  · 결과 요약(300자 이내) 제공
  · 관련 성경 구절 1개 제시
  · 광고 노출 (비기독교 광고 차단, 기독교 서적/행사만)

[프리미엄 티어: 월 4,900원 / 연 39,000원] — 핵심 수익원
  · 무제한 꿈 해석
  · 심층 해석 (성경적 상징 분석 + 기도 가이드)
  · 꿈 일기 보관 (최대 365일)
  · 관련 성경 구절 5개 + 설교 영상 링크
  · 광고 없음

[프리미엄 플러스: 월 9,900원 / 연 79,000원] — 헤비유저용
  · 프리미엄 모든 기능
  · 주 1회 AI 꿈 묵상 리포트 (개인화)
  · 목회자/상담사 연결 중개 (제휴)
  · 소그룹/셀모임 공유 기능
```

## 4. Go-to-Market (GTM) 전략

### Phase 1: 씨앗 (0~4주, MVP)

**목표:** 첫 100명 베타 유저 확보, 제품-시장 적합성(PMF) 검증

**채널:**
1. **개인 SNS + 기독교 커뮤니티 직접 포스팅**
   - 목표: 페이스북 기독교 그룹 ("크리스천 교제", "새벽기도 나눔방" 등)
   - 방법: "베타 테스터 모집" 게시물, 무료 이용권 제공
   - 비용: 0원

2. **카카오 오픈채팅 기독교 채널**
   - 새벽기도, 성경공부, QT 관련 오픈채팅방 타겟
   - 방법: 직접 참여 후 자연스러운 공유
   - 비용: 0원

3. **네이버 블로그 SEO 콘텐츠 (선행 작업)**
   - "성경에서 꿈의 의미", "꿈 속 뱀은 성경적으로?", "기독교 꿈 해석"
   - 검색 트래픽 → 앱 설치 전환 퍼널 구축
   - 비용: 0원 (시간 투자)

### Phase 2: 싹 (1~3개월, 초기 성장)

**목표:** MAU 5,000, 유료 250명, PMF 확인

**채널:**
1. **기독교 유튜버 협업 (마이크로 인플루언서)**
   - 구독자 1~10만 명의 목사/전도사 유튜버 타겟
   - 제안: 무료 프리미엄 계정 + 매출 일부 공유 (affiliate 10%)
   - 비용: 성과 기반 (초기 현금 지출 없음)
   - 예시 채널: 청년부 목사 유튜브, QT 나눔 채널, CCM 리뷰 채널

2. **교회 소그룹/셀모임 침투 전략**
   - "소그룹 리더 무료 프리미엄" 프로그램
   - 리더 1명이 5~15명 멤버에게 자연 전파
   - 비용: 리더 계정 무료 제공 (서버비만 발생)

3. **갓피플/기독교 커뮤니티 사이트 배너 광고 테스트**
   - 갓피플, 기독일보, 크리스천투데이 등 소규모 배너
   - 예산: 월 30~50만 원 (ROI 검증 후 확대)

### Phase 3: 성장 (3~12개월)

**목표:** MAU 20,000 → 60,000, 수익화 본격화

**채널:**
1. **두란노/CGNTV 파트너십 타진**
   - 두란노: 기독교 출판/콘텐츠 1위, 기독교 리더 신뢰도 최고
   - CGNTV: 비상업적 후원 기반 방송 (광고 불가, 콘텐츠 협력 가능)
   - 접근: 공동 QT 콘텐츠 제작 or 앱 소개 아티클 기고
   - 비용: 콘텐츠 협력 (현금 지출 최소화)

2. **기독교 행사/수련회 스폰서십**
   - 청년부 수련회, 여름성경학교 등
   - 방법: QR코드 배포, 현장 체험 부스
   - 비용: 행사당 50~100만 원

3. **카카오 채널 + 카카오톡 알림톡**
   - "오늘의 꿈 묵상" 새벽 5시 발송 자동화
   - 비용: 메시지당 15~25원 (카카오 비즈메시지)

4. **ASO (앱스토어 최적화)**
   - 키워드: "기독교 꿈", "성경 꿈 해석", "꿈해몽 성경"
   - 구글플레이 피처드 앱 신청 (기독교 카테고리)

## 7. SWOT 분석

### Strengths (강점)

| 강점 | 설명 |
|------|------|
| 니치 시장 독점 | 기독교 관점 AI 꿈 해석은 경쟁자 없는 블루오션 |
| 높은 신뢰도 기반 | 성경 구절 근거 해석 → 점술 이미지 탈피 |
| 강한 커뮤니티 | 교회 소그룹 → 자연 바이럴 네트워크 |
| 낮은 기술 허들 | LLM API + 성경 RAG로 빠른 MVP 가능 |
| 반복 사용 유인 | 꿈은 매일 꿈 → DAU 높을 가능성 |

### Weaknesses (약점)

| 약점 | 설명 |
|------|------|
| 신학적 논란 가능성 | 일부 보수 신학자의 "꿈 해석 = 신비주의" 비판 |
| 타겟 고령화 | 개신교 60세 이상 44% → 앱 이탈률 높을 수 있음 |
| 결제 저항 | "하나님 말씀에 돈을 받나" 정서 |
| 1인 운영 한계 | CS, 마케팅, 개발 동시 수행 부담 |

### Opportunities (기회)

| 기회 | 설명 |
|------|------|
| 유반젤리즘 트렌드 | 디지털 신앙생활 급성장, 앱 수용성 증가 |
| 글로벌 확장 | 재외 한인 기독교인 + 영어권 확장 가능 |
| 기독교 AI 선점 | GOODTV AI 플랫폼 추진 발표 → 시장 형성 중 |
| 수련회/행사 시즌 | 여름/겨울 수련회 → 시즌 트래픽 급증 예측 |

### Threats (위협)

| 위협 | 설명 |
|------|------|
| 교단 공식 반대 성명 | 대형 교단이 "AI 꿈 해석 금지" 입장 낼 경우 |
| 갓피플/대형 앱 진출 | 기존 성경 앱이 동일 기능 추가 시 위협 |
| AI 환각(Hallucination) | 잘못된 성경 해석 → 영적 피해 클레임 |

## 8. 리스크 분석 & 대응 전략

### 리스크 1: 신학적 논란 (심각도: 高)

**시나리오:** 보수적 교단 또는 저명한 목사가 "AI 꿈 해석은 비성경적" 공개 비판

**대응:**
- 서비스 명칭을 "꿈 해몽"이 아닌 **"꿈 묵상 가이드"** 또는 **"성경으로 꿈 돌아보기"** 로 프레임
- 결과물에 항상 면책 문구: *"이 해석은 AI가 성경 말씀을 기반으로 제공하는 묵상 자료이며, 예언 또는 신탁이 아닙니다"*
- 자문 목사/신학자 1~2명 확보 (공신력 확보)
- 성경 구절 인용 비율 높게 유지 (AI 창작 최소화)

### 리스크 2: 법적/앱스토어 규제 (심각도: 중)

**시나리오:** 구글플레이/애플 앱스토어가 "점술" 카테고리로 분류하여 노출 제한

**대응:**
- 카테고리: "건강 및 피트니스 > 명상" 또는 "교육 > 종교" 로 등록
- 앱 소개에 "점술, 운세, 해몽" 키워드 배제, "성경, 묵상, 기도" 강조
- 웹앱(PWA) 병행 운영으로 앱스토어 의존도 분산
- 한국 게임물관리위원회(GRAC) 심의: "교육" 등급 취득 목표

### 리스크 3: AI 오류 및 클레임 (심각도: 중)

**시나리오:** AI가 잘못된 성경 해석 제공 → 사용자가 이를 "신의 계시"로 오해

**대응:**
- 모든 해석에 **성경 구절 원문 링크** 필수 첨부 (사실 검증 가능)
- 프롬프트 엔지니어링: "이것은 하나님의 뜻이 아닌 묵상 자료입니다" 강제 출력
- 이용약관에 AI 특성 및 면책 조항 명시
- 해석 결과 신고 기능 + 사람 리뷰 워크플로우 구축

### 리스크 4: 기독교 커뮤니티 반발 (심각도: 중)

**시나리오:** "꿈 해석 = 무속신앙" 프레임으로 기독교 커뮤니티 내 불매 운동

**대응:**
- 초기 베타에서 신뢰할 수 있는 목사/사역자 그룹 먼저 검증
- 창세기 요셉, 다니엘 등 성경의 꿈 해석 사례를 전면에 부각
- "교회 추천 앱" 포지셔닝 전략 (top-down 신뢰 확보)

### 인디 개발자로서 핵심 원칙 3가지

1. **빠른 출시 > 완벽한 제품**: 4주 안에 작동하는 MVP를 커뮤니티에 공개하라. 신학적 완성도는 베타 과정에서 다듬는다.
