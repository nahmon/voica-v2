# 04. 모바일 UX & 반응형 디자인 분석

> **분석 관점:** Uber Senior UX Researcher (Mobile UX & Cross-Device Experience)
> **분석 일자:** 2026-04-14

---

## 1. 모바일 UX 분석 (Mobile UX Analysis)

### 1.1 터치 타겟

| 요소 | 추정 크기 | 최소 권장 (iOS/Android) | 평가 |
|------|----------|----------------------|------|
| "+ 새 견적서" 버튼 | ~120x40px | 44x44px / 48x48dp | 충족 |
| "첫 견적서 만들기 →" CTA | ~280x48px (풀폭) | 44x44px / 48x48dp | 양호 -- 넉넉한 터치 영역 |
| 피처 카드 (비인터랙티브) | ~160x80px | N/A | 해당 없음 |
| "QuoteBridge" 로고 | ~130x24px | 44x44px / 48x48dp | **미흡** -- 높이가 24px로 작음 |

**[Severity: Low]** 로고 터치 타겟이 iOS Human Interface Guidelines 최소 기준(44px) 미달. 다만 로고 클릭은 핵심 행동이 아니므로 영향 낮음.

**[Severity: Low]** 전반적으로 터치 타겟은 양호한 편. CTA 버튼이 풀폭에 가까운 크기로 렌더링되어 엄지 영역(thumb zone)에서 접근하기 용이하다.

### 1.2 엄지 영역 (Thumb Zone) 분석

모바일(375x812) 기준 Uber의 "Thumb-First" 원칙 적용:

```
┌─────────────────────┐
│  [Logo]  [+ 새 견적서]│ ← 상단 네비: 오른손 엄지 도달 어려움 (보조 영역)
│                     │
│       📋            │ ← 히어로 아이콘: 시각적 요소 (터치 불필요)
│   견적서 한 장,      │
│   30초면 됩니다.     │ ← 텍스트: 읽기 전용
│                     │
│  거래처 정보와 품목만  │
│  QuoteBridge가 PDF... │
│                     │
│ [  첫 견적서 만들기 →  ]│ ← CTA: 자연스러운 엄지 도달 영역 ✓
│                     │
│  [30초 완성] [PDF 발송]│ ← 피처 카드: 비인터랙티브
│     [다국어·다통화]    │
└─────────────────────┘
```

**평가:** CTA 버튼이 화면 중앙~하단부에 위치하여 엄지 도달이 용이하다. 이 점은 양호하다.

### 1.3 스크롤 동작

**[Severity: Low]** 모바일에서 전체 콘텐츠가 1스크롤 이내에 표시된다. 스크롤 필요성이 낮아 정보 발견성은 좋으나, 이는 콘텐츠가 극히 적기 때문이다.

## 2. 반응형 디자인 분석 (Responsive Design)

### 2.1 브레이크포인트

| 뷰포트 | 레이아웃 변화 | 평가 |
|--------|-------------|------|
| Desktop (1280px) | 3열 피처 카드, 중앙 정렬 히어로 | 양호 |
| Mobile (375px) | 2+1 피처 카드, 풀폭 CTA | 부분적 |
| Tablet (~768px) | 미확인 | 위험 |

### 2.2 텍스트 리플로우

**[Severity: High]** 모바일(375px)에서 서브텍스트 줄바꿈 문제:

```
데스크톱:
"거래처 정보와 품목만 넣으면 QuoteBridge가 PDF까지 완성해드립니다."

모바일 (실제):
"거래처 정보와 품목만 넣으면"
"QuoteBridge가 PDF까지 완성해드립니"
"다."

모바일 (개선 후, word-break: keep-all):
"거래처 정보와 품목만 넣으면"
"QuoteBridge가 PDF까지"
"완성해드립니다."
```

한국어 텍스트에서 `word-break: keep-all`이 적용되지 않아 조사 "다."가 분리되는 문제. CSS 한 줄로 해결 가능.

### 2.3 피처 카드 그리드

**[Severity: Medium]** 모바일에서 3개 카드가 2+1 배치:

```
데스크톱:  [카드1] [카드2] [카드3]    ← 3열 균등, 양호

모바일:    [카드1] [카드2]            ← 2열
              [카드3]                ← 1열 (고아 카드, 중앙 정렬)
```

3번째 카드가 홀로 놓여 시각적 불균형 발생. 모바일에서는 1열 풀폭 스택이 더 자연스러움:

```
개선안:    [    카드1    ]
           [    카드2    ]
           [    카드3    ]
```

## 3. 크로스 디바이스 일관성

### 3.1 데스크톱-모바일 패리티

| 요소 | 데스크톱 | 모바일 | 일관성 |
|------|---------|--------|--------|
| 네비게이션 | 로고 + 버튼 | 동일 | 일관 |
| 히어로 헤딩 | 큰 볼드 텍스트 | 약간 축소 | 일관 |
| CTA | 중앙 정렬 버튼 | 풀폭 버튼 | 적절한 적응 |
| 피처 카드 | 3열 | 2+1열 | 부분적 |
| 하단 여백 | 과도한 빈 공간 | 과도한 빈 공간 | 일관 (둘 다 문제) |

**[Severity: Low]** 기본적인 반응형 적응은 작동한다. 콘텐츠가 극히 적어 크로스 디바이스 문제가 적은 것이지, 디자인 시스템이 잘 구축된 것은 아니다.

### 3.2 누락된 디바이스 고려

**[Severity: Medium]** 다음 디바이스/환경이 고려되지 않았다:
- **태블릿 (768-1024px):** 별도 브레이크포인트 없음
- **대형 모니터 (1440px+):** 콘텐츠가 좁은 영역에 갇혀 좌우 과도한 여백
- **폴더블 (Galaxy Z Fold):** 내부 화면(882px)에서 데스크톱/모바일 전환 혼란
- **다크 모드:** 지원 없음
- **고대비 모드:** 지원 없음

## 4. 성능 & 기술 분석

### 4.1 페이지 로드

**[Severity: Medium]** 랜딩 페이지가 단순한 만큼 로드 속도는 빠를 것으로 추정되나, 다음 사항이 우려된다:
- SPA 프레임워크 사용 시 초기 JS 번들 크기
- 이모지 외 이미지 리소스가 없어 LCP는 양호할 것
- FCP/LCP 실측 데이터 없음

### 4.2 PWA 준비도

**[Severity: Low]** PWA 관련 요소가 감지되지 않았다:
- `manifest.json` 미확인
- Service Worker 미확인
- 오프라인 지원 없음
- 홈 화면 추가 기능 없음

B2B SaaS 특성상 PWA 우선순위는 낮으나, 모바일에서 반복 사용하는 견적서 도구라면 홈 화면 바로가기는 유용할 수 있다.

### 4.3 한국 모바일 환경 특수성

**[Severity: Medium]** 한국 시장 특화 고려사항:
- **카카오톡 인앱 브라우저:** 공유 링크를 통해 유입 가능. 인앱 웹뷰의 CSS 호환성 확인 필요
- **네이버 인앱 브라우저:** 마찬가지
- **삼성 인터넷:** 한국 시장 점유율 높음. `backdrop-filter` 등 모던 CSS 호환성 확인 필요

## 6. 개선 권고 (Uber 모바일-퍼스트 철학 기반)

### Uber 핵심 원칙: "모바일은 데스크톱의 축소판이 아니라, 별도의 경험이다"

### 6.1 즉시 조치

1. **`word-break: keep-all` 글로벌 적용** -- 한 줄 CSS로 전체 한국어 줄바꿈 문제 해결
2. **모바일 피처 카드 1열 스택** -- 2+1 → 1+1+1 풀폭으로 변경
3. **iOS `100vh` 버그 대응** -- `100dvh` 사용 또는 JS 기반 뷰포트 높이 계산

### 6.2 단기 개선

4. **태블릿 브레이크포인트 추가 (1024px)** -- 피처 카드, 히어로 레이아웃 최적화
5. **카카오톡/네이버 인앱 브라우저 호환성 테스트** -- 한국 사용자의 실제 유입 경로
6. **터치 피드백 추가** -- `:active` 상태에서의 시각적 피드백 (호버 대체)

### 6.3 중기 개선

7. **PWA manifest 추가** -- 홈 화면 바로가기, 앱 아이콘
8. **다크 모드 지원** -- `prefers-color-scheme` 미디어 쿼리
9. **`prefers-reduced-motion` 대응** -- 향후 애니메이션 추가 시 필수

---

*Uber의 모바일 UX 교훈: "사용자는 이동 중에, 한 손으로, 주의가 분산된 상태에서 앱을 사용한다." QuoteBridge의 핵심 가치 '30초 견적서'는 본질적으로 모바일-퍼스트 시나리오에 적합하다. 모바일 경험이 데스크톱보다 더 중요할 수 있다.*
