# 01. 첫인상 & 정보 구조 분석

> **분석 관점:** Uber Senior UX Researcher
> **분석 일자:** 2026-04-14

## 1. 첫인상 분석 (First Impression Analysis)

### 1.1 5초 테스트 시뮬레이션

사용자가 페이지에 도착한 후 5초 내에 인지할 수 있는 정보:

| 시간 | 인지 요소 | 평가 |
|------|----------|------|
| 0-1초 | 웜 베이지 배경 + 클립보드 이모지 | 부드러운 첫인상, 그러나 "무엇을 하는 서비스인지" 불명확 |
| 1-3초 | "견적서 한 장, 30초면 됩니다" 헤딩 | 핵심 가치 제안 전달 -- **명확하고 효과적** |
| 3-5초 | 서브텍스트 + CTA 버튼 인지 | "거래처 정보와 품목만 넣으면 PDF 완성" -- 작동 방식 이해 |

**[Severity: Medium]** 가치 제안 문구 자체는 우수하다. "30초"라는 구체적 시간과 "PDF까지 완성"이라는 결과물을 명시하여, B2B 사용자가 즉시 기대 가치를 이해할 수 있다. 그러나 **시각적 증거가 부재**한다 -- 실제 견적서 PDF 미리보기, 제품 스크린샷, 또는 데모 GIF가 없어 "정말 그런가?"라는 의문이 해소되지 않는다.

### 1.2 감정적 반응 분석

| 의도된 감정 | 실제 유발 감정 | 간극 |
|------------|--------------|------|
| "이거 빠르고 편하겠다" (기대) | "아직 만들고 있나?" (불안) | 큰 간극 |
| "전문적인 도구다" (신뢰) | "개인 프로젝트 같다" (의구심) | 큰 간극 |
| "써보고 싶다" (행동 의지) | "더 알아봐야겠다" (유보) | 중간 간극 |

**[Severity: High]** 페이지 전체에서 "미완성" 느낌이 강하다. 이는 콘텐츠 부족(단일 섹션), 비주얼 미완(이모지 아이콘), 구조적 공백(푸터 없음)의 복합 결과다.

### 1.3 신뢰 신호 감사 (Trust Signal Audit)

B2B SaaS 랜딩 페이지에서 기대되는 신뢰 신호:

| 신뢰 요소 | 존재 여부 | 심각도 |
|----------|----------|--------|
| 고객사 로고 / "Trusted by" | 없음 | Critical |
| 사용자 후기 / 추천사 | 없음 | Critical |
| 사용자 수 / 통계 | 없음 | High |
| 회사 정보 (대표, 주소) | 없음 | High |
| 가격 정보 | 없음 | High |
| 보안 인증 / 배지 | 없음 | Medium |
| 언론 보도 / 수상 내역 | 없음 | Low |
| FAQ / 도움말 | 없음 | Medium |
| 연락처 (이메일, 전화) | 없음 | High |

**[Severity: Critical]** 13개 표준 신뢰 요소 중 0개가 존재한다. B2B 구매 의사결정에서 신뢰는 기능보다 선행한다. 아무리 좋은 제품이라도 "이 회사가 누구인지"조차 알 수 없으면 기업 담당자는 사용을 검토하지 않는다.

## 2. 정보 구조 분석 (Information Architecture)

### 2.1 네비게이션 구조

```
현재 사이트맵:
/               ← 랜딩 페이지 (유일하게 작동하는 페이지)
/new            ← 404 NOT_FOUND (CTA 목적지)

네비게이션 요소:
├── [Logo] QuoteBridge  → / (홈)
└── [Button] + 새 견적서 → /new (404)
```

**[Severity: Critical]** 사이트 전체가 단일 페이지로 구성되어 있으며, 그 유일한 행동 유도 경로가 404로 끝난다. 이는 **정보 구조 이전의 문제** — 구조 자체가 존재하지 않는다.

### 2.2 콘텐츠 계층 구조

```
현재 계층:
1. 헤딩: "견적서 한 장, 30초면 됩니다"     ← 가치 제안 (WHAT)
2. 서브텍스트: "거래처 정보와 품목만..."     ← 작동 방식 (HOW)
3. CTA: "첫 견적서 만들기 →"              ← 행동 유도 (DO)
4. 피처 카드 x3: 속도, PDF, 다통화         ← 부가 가치 (WHY)

누락된 계층:
- WHO: 누가 만들었는가? (회사 정보)
- FOR WHOM: 누구를 위한 서비스인가? (타겟 사용자)
- HOW MUCH: 얼마인가? (가격)
- PROOF: 실제 효과가 있는가? (소셜 프루프)
- TRUST: 안전한가? (보안, 약관)
- HELP: 문제가 생기면? (고객 지원)
```

**[Severity: High]** WHAT-HOW-DO 구조는 갖춰졌으나, B2B 구매 결정에 필수적인 WHO-PROOF-TRUST 레이어가 전면 부재하다.

### 2.3 Findability (정보 탐색성)

- **[Severity: Critical]** 사용자가 원하는 정보를 찾을 방법이 없다. 검색, 메뉴, 푸터 링크, 사이트맵 어느 것도 존재하지 않는다.
- **[Severity: High]** 가격 정보를 찾으려는 사용자 → 경로 없음 → 이탈
- **[Severity: High]** 고객 지원에 접근하려는 사용자 → 경로 없음 → 이탈
- **[Severity: Medium]** SEO 관점: 푸터, 내부 링크, sitemap.xml, 구조화 데이터 부재로 검색 엔진 인덱싱이 극히 제한적

## 3. 이슈 우선순위

| 순위 | 심각도 | 이슈 | Uber 관점 평가 |
|------|--------|------|---------------|
| 1 | Critical | CTA → 404 (전환 경로 차단) | "사용자가 목적지에 도달할 수 없다" -- Uber에서는 출발지-목적지 연결이 불가능한 것과 동일한 수준의 장애 |
| 2 | Critical | 신뢰 요소 0/13 | B2B 사용자는 "누가 만들었는지" 모르는 서비스에 회사 거래 정보를 입력하지 않는다 |
| 3 | Critical | 사이트맵 = 단일 페이지 | 랜딩 페이지만으로는 구매 의사결정에 필요한 정보를 제공할 수 없다 |
| 4 | High | 콘텐츠 계층 불완전 | WHO, PROOF, TRUST 레이어 부재 |
| 5 | High | 시각적 증거 부재 | 제품 스크린샷이나 데모 없이 가치 제안을 "말로만" 전달 |
| 6 | Medium | SEO 구조 미비 | 검색 유입 경로 차단 |
| 7 | Low | 네비게이션 확장성 부재 | 현재는 2개 링크뿐이나, 향후 콘텐츠 증가 시 구조 부재가 걸림돌 |

## 4. 개선 권고 (Uber 디자인 철학 기반)

### Uber 핵심 원칙: "목적지까지의 마찰을 0으로"

Uber의 UX 철학은 "사용자가 원하는 것을 가장 빠르게 달성하도록 하라"이다. QuoteBridge에 적용하면:

### 4.1 즉시 조치 (This Week)

1. **`/new` 경로 복구 또는 CTA 목적지 변경** -- 전환 경로가 완전히 차단된 상태. 최소한의 견적서 작성 폼이라도 연결하거나, "Coming Soon" 페이지로 대체할 것.

2. **최소 푸터 추가** -- 회사명, 이메일, 사업자등록번호, 이용약관/개인정보처리방침 링크. 한국 전자상거래법 준수를 위해서도 필수.

3. **제품 스크린샷 또는 PDF 미리보기 추가** -- 히어로 섹션에 실제 견적서 결과물을 보여줘 "30초 완성"의 시각적 증거를 제공.

### 4.2 단기 개선 (2주 내)

4. **"How It Works" 섹션 추가** -- 3단계 프로세스: 정보 입력 → 자동 생성 → PDF 발송. Uber의 "3 Steps to Ride" 패턴 참고.

5. **소셜 프루프 섹션 추가** -- 사용자 수 카운터, 고객사 로고, 또는 초기 사용자 추천사 1-2개.

6. **가격 페이지 추가** -- 무료 체험이 있다면 이를 CTA에 명시 ("무료로 첫 견적서 만들기").

### 4.3 중기 개선 (1개월 내)

7. **완전한 사이트맵 구성** -- 홈, 기능, 가격, 고객 사례, 도움말, 회사 소개
8. **반응형 네비게이션 시스템** -- 모바일 햄버거 메뉴, 데스크톱 탑 네비
9. **커스텀 404 페이지** -- 브랜드 일관성 유지 + 홈으로 돌아가기 CTA

---

*Uber의 초기 성장에서 배울 점: 완벽한 제품보다 "작동하는 핵심 경로"가 우선이다. QuoteBridge의 핵심 경로 "랜딩 → 견적서 작성 → PDF 생성"이 끊김 없이 작동하는 것이 모든 디자인 개선보다 선행되어야 한다.*
