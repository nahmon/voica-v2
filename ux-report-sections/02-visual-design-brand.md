# 02. 비주얼 디자인 & 브랜드 아이덴티티 분석

> **분석 관점:** Airbnb Senior UX Researcher (Visual Design & Brand Identity)
> **분석 일자:** 2026-04-14

---

## 1. 비주얼 디자인 분석 (Visual Design Analysis)

### 1.1 컬러 시스템

| 요소 | 사용 색상 | 비고 |
|------|----------|------|
| 배경 | 웜 베이지/크림 (#F5F0E8 추정) | 단일 배경색, 전체 페이지 동일 |
| 헤딩 텍스트 | 블랙 (#1A1A1A 추정) | 고대비, 가독성 양호 |
| 서브텍스트 | 미디엄 그레이 (#6B6B6B 추정) | 계층 구분 역할 |
| CTA 버튼 | 블랙 배경 + 화이트 텍스트 | 유일한 인터랙티브 강조 |
| 피처 카드 | 화이트 배경 + 연한 보더 | 콘텐츠 영역 분리 |

**[Severity: High]** 브랜드 컬러 부재. 블랙+베이지만으로는 QuoteBridge만의 색상 아이덴티티가 형성되지 않는다. 경쟁 B2B SaaS(토스, 채널톡, 리멤버 등)는 모두 명확한 프라이머리 컬러를 보유하고 있다. 현재 팔레트는 "무인상점" 느낌으로, 신뢰와 전문성보다는 미완성 인상을 준다.

**[Severity: Medium]** 액센트 컬러 부재. 사용자의 시선을 유도할 보조 색상이 없어 시각적 위계가 사이즈와 굵기에만 의존하고 있다.

**개선 권고:** Airbnb의 Rausch Pink(#FF5A5F)이 브랜드 전체를 관통하듯, QuoteBridge에도 하나의 명확한 프라이머리 컬러가 필요하다. 견적서의 "신속함"과 "정확함"을 전달할 수 있는 색상(예: 딥 블루, 테크 퍼플, 또는 민트 그린)을 CTA, 아이콘, 강조 텍스트에 일관 적용할 것을 권고한다.

### 1.2 타이포그래피 위계

| 레벨 | 용도 | 스타일 |
|------|------|--------|
| H1 | "견적서 한 장, 30초면 됩니다." | 볼드 산세리프, ~36-40px |
| 서브헤딩 | "거래처 정보와 품목만 넣으면..." | 레귤러, 미디엄 그레이, ~16-18px |
| 카드 타이틀 | "30초 완성", "PDF 즉시 발송" 등 | 미디엄 볼드, ~14-15px |
| 카드 서브타이틀 | "자동완성", "원클릭" 등 | 레귤러, 라이터 그레이, ~12-13px |

**[Severity: Medium]** 타이포그래피 계층은 기능적으로 작동하나, 단 4단계로 매우 제한적이다. 향후 콘텐츠 확장 시 확장 가능한 타입 스케일이 정의되어 있지 않다.

**[Severity: High]** 모바일에서 서브헤딩 줄바꿈 문제. "QuoteBridge가 PDF까지 완성해드립니" + "다."로 어색하게 분리된다.

**개선 권고:**
- `word-break: keep-all` CSS로 한국어 조사 분리 방지
- 8단계 이상의 타입 스케일(Display, H1~H4, Body L/M/S, Caption)을 디자인 토큰으로 정의
- Pretendard, SUIT 등 한국어 최적화 산세리프 도입 권고

### 1.3 공간 및 시각적 리듬

**[Severity: Medium]** 페이지 하단에 과도한 빈 공간(dead space)이 존재한다. 푸터가 전혀 없어 페이지가 "끝나지 않은" 것처럼 보인다.

**[Severity: Low]** 데스크톱에서 콘텐츠 영역이 좁게 집중되어 좌우 여백이 과도하다. 1440px 이상 대형 모니터에서는 더 심할 것이다.

**개선 권고:** 하단 dead space를 신뢰 요소(고객사 로고, 보안 인증, 사용 통계)나 간결한 푸터로 채울 것. 4px 또는 8px 베이스의 스페이싱 스케일을 디자인 토큰으로 명시할 것.

## 2. 브랜드 아이덴티티 (Brand Identity)

### 2.1 브랜드 인지

| 의도된 인상 (추정) | 실제 전달되는 인상 | 간극 |
|-------------------|-------------------|------|
| 빠르고 전문적인 B2B 도구 | 미완성 MVP / 사이드 프로젝트 | 큰 간극 |
| 신뢰할 수 있는 비즈니스 파트너 | 개인 개발자의 실험 프로젝트 | 큰 간극 |
| 글로벌 역량 (다국어/다통화) | 로컬 소규모 도구 | 중간 간극 |

**[Severity: Critical]** B2B SaaS에서 랜딩 페이지의 시각적 완성도는 곧 "이 서비스에 우리 회사의 견적서를 맡겨도 되는가?"에 대한 첫 번째 답변이다. 현재 페이지는 그 질문에 "아직 준비 중"이라고 답하고 있다.

### 2.2 이모지 vs. 커스텀 아이콘

- 히어로: 클립보드 이모지 (📋) -- OS/브라우저별 다르게 렌더링
- 피처 카드: ⚡, 📄, 🌏 이모지

**[Severity: High]** 이모지는 크로스 플랫폼 비일관성 문제가 있다. macOS, Windows, Android에서 완전히 다른 비주얼을 보여준다. B2B 맥락에서 "캐주얼" 내지 "비전문적" 신호를 보낸다.

**[Severity: Medium]** 히어로의 클립보드 이모지는 "견적서"라는 개념을 충분히 전달하지 못한다. 실제 견적서 PDF 미리보기(mock-up)가 훨씬 효과적일 것이다.

**개선 권고:** 커스텀 SVG 아이콘 세트를 제작할 것. 최소:
1. 히어로: 실제 견적서 PDF 목업 일러스트레이션
2. 피처 카드: 통일된 스타일의 커스텀 아이콘
3. 브랜드 프라이머리 컬러를 아이콘에 적용

### 2.3 브랜드 차별화

**[Severity: High]** QuoteBridge를 다른 견적 SaaS와 구별할 시각적 요소가 전무하다. "QuoteBridge" 텍스트를 다른 서비스명으로 바꾸면 동일한 페이지가 어떤 SaaS든 될 수 있다.

**개선 권고:**
- 텍스트 로고를 심볼+워드마크 조합으로 업그레이드 (견적서+다리(bridge) 메타포)
- "30초" 키 메시지를 시각적으로 강화 (타이머 애니메이션 등)
- 제품 스크린샷 또는 데모 GIF를 히어로에 배치

## 3. 디자인 시스템 성숙도

| 단계 | 설명 | 현위치 |
|------|------|--------|
| Level 0 | 디자인 시스템 없음 | |
| **Level 1** | **기본 일관성, 비공식 패턴** | **현재** |
| Level 2 | 문서화된 컴포넌트, 디자인 토큰 | 목표 |
| Level 3 | 공유 라이브러리, 거버넌스 | 장기 목표 |

**[Severity: Critical]** 404 페이지가 Vercel 기본 에러 페이지 그대로 노출됨. 기술 ID(icn1::ssdln-...)가 사용자에게 그대로 노출되어 기술적 미숙함을 직접 드러낸다.

## 4. Airbnb 디자인 철학 기반 개선 권고

### 4.1 Belonging (소속감) → 신뢰감
- **고객사 로고 배너**: "000개 기업이 QuoteBridge로 견적서를 보내고 있습니다"
- **실제 견적서 PDF 미리보기**: 사용자가 자신의 회사가 이 수준의 견적서를 보내는 모습을 상상할 수 있게
- **보안/인증 배지**: SSL, 데이터 암호화 등

### 4.2 Warmth (온기) → 접근성
- 웜 베이지 톤 유지하되, 프라이머리 컬러(딥 네이비 또는 인디고)와 조합
- "첫 견적서 만들기"에 "무료, 가입 없이" 진입 장벽 해소 문구 추가

### 4.3 Craftsmanship (장인정신) → 완성도
- **커스텀 404 페이지**: 브랜드 로고 + "견적서 만들러 가기" CTA
- **이모지→커스텀 아이콘**: 48px SVG 아이콘 3종 (Phosphor/Heroicons 기반)
- **푸터 추가**: 회사 정보, 이용약관, 개인정보처리방침

---

## 5. Quick Wins (1주 이내)

1. `word-break: keep-all` 적용 (30분)
2. 커스텀 404 페이지 구현 (2시간)
3. 이모지를 SVG 아이콘으로 교체 (2시간)
4. 최소 푸터 추가 (1시간)
5. 브랜드 프라이머리 컬러 1종 선정 후 CTA 적용 (1시간)
