## 1. 인터랙션 디자인 분석 (Interaction Design Analysis)

### 1.1 클릭 타겟 & 어포던스

| 요소 | 유형 | 어포던스 | 작동 여부 | 평가 |
|------|------|---------|----------|------|
| "QuoteBridge" 로고 | 링크 | 홈으로 이동 기대 | 작동 (/ 로 이동) | 양호 |
| "+ 새 견적서" 버튼 | 링크/버튼 | 견적서 작성 시작 기대 | **404 오류** | Critical |
| "첫 견적서 만들기 →" CTA | 링크/버튼 | 견적서 작성 시작 기대 | **404 오류** | Critical |
| 피처 카드 3종 | 정보 카드 | 클릭 불가 (정보 전달용) | N/A | 양호 |

**[Severity: Critical]** 페이지의 2개 인터랙티브 요소 중 2개(100%)가 broken. 사용자에게 제공되는 모든 행동 경로가 실패한다.

### 1.2 피드백 패턴

| 인터랙션 | 기대 피드백 | 실제 피드백 | 평가 |
|----------|-----------|-----------|------|
| CTA 호버 | 색상 변경/그림자 | 확인 불가 (스냅샷 기반) | - |
| CTA 클릭 | 페이지 전환 애니메이션 | Vercel 404 페이지 (하드 전환) | Critical |
| 로고 클릭 | 부드러운 전환 | 페이지 리로드 | Medium |

**[Severity: Critical]** CTA 클릭 시 Vercel 기본 404 페이지가 노출된다. 에러 메시지에 기술 ID(`icn1::ssdln-1776169587232-954c3de07844`)가 포함되어, 기술적 장애를 사용자에게 직접 노출한다. Google의 "Helpful error" 원칙에 정면 위배.

### 1.3 마이크로인터랙션

**[Severity: Medium]** 페이지 전체에서 마이크로인터랙션이 감지되지 않았다:
- 페이지 로딩 애니메이션 없음
- 스크롤 기반 요소 등장(fade-in) 없음
- CTA 호버/클릭 피드백 미확인
- 피처 카드 등장 애니메이션 없음

Material Design에서는 모든 상태 전환에 의미 있는 모션을 권장한다. 현재 페이지는 완전히 정적이다.

## 2. 사용자 플로우 분석 (User Flow Analysis)

### 2.1 핵심 사용자 여정 (Critical Path)

```
의도된 플로우:
[랜딩] → [CTA 클릭] → [견적서 작성] → [PDF 생성] → [발송]

실제 플로우:
[랜딩] → [CTA 클릭] → [404 NOT_FOUND] → [??? 막다른 길]
                                           ↓
                                    [브라우저 뒤로가기]
                                           ↓
                                    [랜딩 (원점)]
```

**[Severity: Critical]** 핵심 사용자 여정이 2단계에서 완전히 차단된다. 사용자는:
1. 랜딩 페이지에서 가치를 인지하고
2. CTA를 클릭하여 행동 의지를 표현했으나
3. 404로 막히며 신뢰가 깨지고
4. 대안 경로가 없어 이탈한다

이는 Google의 "User Journey Mapping" 프레임워크에서 **완전한 플로우 단절(flow break)**로 분류되며, 가장 높은 우선순위로 해결해야 한다.

### 2.2 대안 경로 분석

| 사용자 의도 | 가능한 경로 | 결과 |
|------------|-----------|------|
| 견적서 만들기 | CTA 클릭 | 404 |
| 가격 확인 | 없음 | 이탈 |
| 서비스 이해 | 랜딩만 읽기 | 불완전 |
| 고객 지원 | 없음 | 이탈 |
| 데모 보기 | 없음 | 이탈 |
| 로그인/가입 | 없음 | 이탈 |

**[Severity: Critical]** 사용자가 취할 수 있는 의미 있는 행동이 **0개**이다. 읽기 전용 브로셔와 동일한 상태.

### 2.3 에러 복구 (Error Recovery)

**[Severity: High]** 404 페이지에서의 복구 경로:
- 브라우저 뒤로가기 → 랜딩 (유일한 복구)
- 404 페이지 내 네비게이션 → Vercel 기본 문서 링크 (외부 이탈)
- 홈 링크 → 없음 (404 페이지에 사이트 네비게이션 없음)

Google의 에러 페이지 가이드라인: 에러 상태에서도 사용자가 유용한 행동을 할 수 있어야 한다.

## 3. 접근성 분석 (Accessibility)

### 3.1 시맨틱 HTML

| 요소 | 시맨틱 태그 | 평가 |
|------|-----------|------|
| 네비게이션 | `<navigation>` | 양호 |
| 메인 콘텐츠 | `<main>` | 양호 |
| 헤딩 | `<h1>` | 양호 |
| 서브텍스트 | `<p>` | 양호 |
| CTA | `<a>` (링크) | 주의: 버튼 역할이나 `<a>` 사용 |
| 피처 카드 | `<div>` (비시맨틱) | 미흡 |

### 3.2 스크린 리더 호환성

**[Severity: Medium]** 이모지 아이콘 문제:
- 📋 → "클립보드" 또는 "clipboard" (스크린 리더가 이모지 이름 낭독)
- ⚡ → "번개" 또는 "high voltage"
- 📄 → "문서" 또는 "page facing up"
- 🌏 → "아시아가 보이는 지구" 또는 "globe showing Asia-Australia"

이모지의 스크린 리더 출력이 컨텍스트와 무관한 경우가 있어 (`aria-label`로 의미 있는 설명 필요), 시각 장애 사용자에게 혼란을 줄 수 있다.

### 3.3 키보드 네비게이션

**[Severity: Medium]** Accessibility snapshot 상 기본적인 키보드 탐색(Tab)은 가능하나:
- Skip-to-content 링크 부재
- 피처 카드에 포커스 인디케이터 없음 (비인터랙티브이므로 낮은 영향)
- 포커스 순서: 로고 → + 새 견적서 → CTA → (카드는 비인터랙티브)

### 3.4 WCAG 2.1 컴플라이언스 추정

| 기준 | 레벨 | 상태 |
|------|------|------|
| 1.1.1 비텍스트 콘텐츠 | A | 미흡 (이모지에 alt/aria-label 없음) |
| 1.3.1 정보와 관계 | A | 부분 충족 (시맨틱 태그 사용, 카드는 div) |
| 2.4.1 블록 건너뛰기 | A | 미충족 (skip-to-content 없음) |
| 2.4.2 페이지 제목 | A | 충족 ("QuoteBridge") |
| 2.4.4 링크 목적 | A | 충족 ("첫 견적서 만들기 →" 명확) |
| 3.1.1 페이지 언어 | A | 미확인 (html lang 속성 확인 필요) |

## 4. 이슈 우선순위

| 순위 | 심각도 | 이슈 | Google Material Design 관점 |
|------|--------|------|-----------------------------|
| 1 | Critical | CTA → 404 (핵심 플로우 차단) | "모든 여정은 사용자를 목적지로 인도해야 한다" |
| 2 | Critical | 대안 경로 0개 | "다양한 사용자 의도에 대응하는 다중 경로 필요" |
| 3 | Critical | 에러 복구 경로 부재 | "에러 상태에서도 유용한 행동이 가능해야" |
| 4 | High | 404 페이지 미커스터마이징 | "에러 메시지는 도움이 되어야 한다" |
| 5 | Medium | 마이크로인터랙션 부재 | "모션은 의미를 전달한다" |
| 6 | Medium | 이모지 접근성 | "모든 사용자가 동등하게 정보에 접근" |
| 7 | Medium | Skip-to-content 부재 | "키보드 사용자 효율성" |

## 5. 개선 권고 (Google Material Design 기반)

### 5.1 즉시 조치

1. **`/new` 경로 복구** -- 핵심 플로우의 연속성 확보가 최우선
2. **커스텀 에러 페이지** -- 브랜드 로고 + 홈 링크 + "견적서 만들기" CTA + 친절한 에러 메시지
3. **이모지에 `aria-label` 추가** -- 스크린 리더 사용자를 위한 의미 있는 설명

### 5.2 단기 개선

4. **`<html lang="ko">` 확인** -- 한국어 페이지의 기본 접근성 요구
5. **피처 카드를 시맨틱 `<article>` 또는 `<section>`으로 변경** -- 구조적 의미 부여
6. **Skip-to-content 링크 추가** -- 키보드 네비게이션 효율성
7. **CTA 호버/클릭 피드백** -- Material Design의 ripple effect 또는 색상 전환

### 5.3 중기 개선

8. **페이지 전환 애니메이션** -- 부드러운 라우팅 전환
9. **스크롤 기반 요소 등장 애니메이션** -- 콘텐츠 발견의 즐거움
10. **온보딩 플로우 설계** -- 첫 방문자를 위한 가이드 투어

---

*Google의 UX 리서치 철학: "사용자의 의도를 존중하라." QuoteBridge의 사용자는 견적서를 만들고 싶어서 CTA를 클릭했다. 그 의도를 404로 배신하는 것은 가장 근본적인 UX 실패이다.*
