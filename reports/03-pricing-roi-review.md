## 문제점 & 리스크

### 1. 가장 심각한 문제: 요금제가 인건비를 반영하지 않음
현재 요금제는 **AI/인프라 비용**(건당 ₩5,000~15,000)만 커버하는 수준으로 설계된 것으로 보임.  
고객지원, 패널 품질 관리, CS, 영업 등 인건비를 전혀 고려하지 않은 구조.

### 2. 볼륨 디스카운트가 역마진을 심화
10건 크레딧의 건당 단가(₩90,000)는 1건(₩120,000)보다 25% 저렴하지만,  
원가 대비로는 더 깊은 적자. 대량 구매자일수록 적자폭 확대.

### 3. 엔터프라이즈 건당 단가(₩60,000)가 가장 위험
"대기업 고객 = 높은 매출"처럼 보이지만 건당 단가가 최저.  
월 20건 처리 = 인건비 배분에 유리하지만, ₩60,000은 AI 비용도 못 커버.

### 4. 연결제 20% 할인이 현금흐름 개선에 도움은 되지만 마진 악화
선불 현금 유입은 긍정적이나, 이미 적자인 요금제에 할인을 얹으면 손실 가중.

### 5. 리워드 수수료 20%의 수익성
리워드 수수료는 별도 수익원. 패널에게 ₩5,000 지급 기준, 75명 × ₩5,000 = ₩375,000 리워드 풀  
수수료 20% = ₩75,000 추가 수익. 이 수익원이 없으면 적자폭은 더 커짐.

## 재설계 요금제

### 설계 원칙
1. **목표 마진율**: 기본 시나리오 기준 최소 20% (15% 목표 + 5% 버퍼)
2. **최소 판매가 계산**: 원가 ₩183,347 ÷ (1 - 0.20 - 0.03) = **₩238,113 / 건** → 약 **₩240,000**
3. **볼륨 디스카운트 상한**: 최대 15% (현행 25%는 마진 파괴)
4. **인건비 절감 로드맵**: 자동화/셀프서브 강화로 건당 인건비 목표 ₩50,000 이하

## 인프라 비용 최적화 방안

### 1. 오디오 스토리지 정책 (현재 정책 없음 → 즉시 도입 필요)

| 기간 | 정책 |
|------|------|
| 0~6개월 | Supabase Storage (Hot) — 즉시 다운로드 |
| 6~12개월 | S3 Standard-IA로 자동 이전 (비용 58% 절감) |
| 12개월 초과 | S3 Glacier로 아카이브 또는 고객 동의 후 삭제 |

예상 절감: 건당 스토리지 비용 ₩209 → **₩105** (50% 절감)

### 2. STT 비용 최적화
- 패널 무응답/침묵 구간 제거 후 STT 처리 (VAD 적용)
- 예상 STT 처리 시간 10~20% 단축 → 건당 ₩350~700 절감

### 3. TTS 캐싱
- 동일 질문 텍스트는 TTS 재생성 없이 캐시 재사용
- 같은 인터뷰 가이드 재사용 시 TTS 비용 0에 수렴

### 4. GPT-4o → 배치 API 활용
- OpenAI Batch API 사용 시 50% 비용 절감
- 실시간 응답 불필요한 리포트 생성에 적용
- 건당 ₩352 → **₩176** 절감

### 5. Supabase 사용량 관리
- Pro Plan ($25/월) 유지, 단 Storage는 S3 직접 연동으로 전환
- DB 쿼리 최적화로 컴퓨팅 비용 절감

## 결론 & 권장사항

### 즉시 조치 (0~1개월)
1. **크레딧 1건 가격을 ₩280,000으로 인상** — 현재 건당 ₩120,000은 원가도 안 나옴
2. **10건 크레딧 최대 할인을 15%로 제한** — ₩900,000 → ₩2,380,000
3. **연결제 할인을 20% → 10%로 조정**
4. **오디오 12개월 보관 → 6개월 후 아카이브 정책 도입**

### 단기 조치 (1~3개월)
5. **구독 플랜 가격 인상**: 스타터 ₩290k → ₩690k, 프로 ₩590k → ₩1,690k
6. **엔터프라이즈를 협의 견적(POC) 방식으로 전환** — 건당 단가 방어
7. **GPT-4o Batch API 전환** — 리포트 생성 비용 50% 절감

### 중기 조치 (3~6개월)
8. **셀프서브 온보딩 강화** — 건당 인건비 ₩175,000 → ₩50,000 목표
9. **오디오 스토리지 S3 직접 연동** — Supabase Storage 병목 해소
10. **패널 리워드 수수료 모델 재검토** — 리워드 풀 규모 확대 시 수수료율 차등화

### 손익분기점 (BEP) 추정
- **낙관 시나리오 원가(₩35,074) 기준**: 현행 크레딧 1건(₩120,000)도 흑자 가능
- **기본 시나리오 원가(₩183,347) 기준**: 재설계 요금제(₩280,000) 기준 월 15건에서 BEP 도달
- **핵심**: 월 20건 이상 안정적으로 처리할 고객을 확보하기 전까지는 **크레딧 단건 판매보다 구독 유도**가 재무적으로 유리
