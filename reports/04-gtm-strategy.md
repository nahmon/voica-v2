## 2. GTM 채널 전략

### 2-1. PLG 바이럴 루프 (리포트 공유 URL)

**작동 방식**
1. 리서처가 인터뷰 완료 → 리포트 생성
2. 리포트 우측 상단 "공유" 버튼 → 고유 URL 생성 (비로그인 열람 가능)
3. 공유 URL 하단 고정 배너: "이 리포트는 Voica로 48시간 안에 만들어졌습니다 → 무료 체험"
4. Voica 워터마크가 공유된 리포트에 포함 → 열람자가 Voica를 인식

**KPI 목표**: 공유 URL 열람→회원가입 전환율 8% 이상  
**구현 난이도**: 낮음 (공개 리포트 URL + 간단한 CTA 배너)  
**우선순위**: 1순위 — 추가 마케팅비 없이 바이럴 달성

**SEO 구현**: 블로그 페이지 `/blog`, 랜딩 페이지 기업별 템플릿 `/templates/[사용사례]`

| 파트너 | 방식 | 목표 |

**B. 리서치 에이전시 리셀 파트너**

- 목표: 에이전시 3곳 계약 → 월 거래액 ₩1,000만 기여

## 3. Activation & Retention 플레이

### 3-1. Time-to-Value: 가입→첫 인터뷰 완료 30분 목표

**현재 예상 흐름과 개선 목표**

| 단계 | 현재 예상 소요 | 목표 소요 | 개선 방법 |
|------|--------------|---------|---------|
| 회원가입 | 3분 | 1분 | 소셜 로그인(구글/카카오) 강제 |
| 인터뷰 가이드 작성 | 20분 | 5분 | 업종별 템플릿 10종 제공 + AI 자동완성 |
| 패널 설정 (필터링) | 10분 | 3분 | 기본 필터 프리셋 (성별/연령/지역) |
| 인터뷰 발송 | 2분 | 1분 | 원클릭 발송 |
| 인터뷰 완료 대기 | 2~24시간 | 2시간 | 온라인 패널 풀 상시 대기 보장 |
| 리포트 열람 | 즉시 | 즉시 | — |

**온보딩 체크리스트 (앱 내 표시)**
```
□ 가이드 완성
□ 패널 20명 설정
□ 인터뷰 발송
□ 첫 5건 완료 알림 설정
```

| 단계 | 액션 | 트리거 조건 |
