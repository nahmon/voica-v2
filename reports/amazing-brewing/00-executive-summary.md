## 4. 실패 원인 분석

### 4.1 내부 요인
1. **과잉 설비 투자**: Series B 자금을 이천 제2브루어리(월 600톤) 증설에 집중 투자. 월 750톤 생산능력 대비 실제 매출은 연 39.5억원에 불과 → 가동률 극히 저조
2. **수익 모델 부재**: 영업손실률 -50% (2024년). 편의점 유통 확대에도 프로모션 비용으로 실질 마진 없음
3. **OEM 저마진 구조**: 자체 브랜드보다 OEM 의존도 높아 수익성 악화
4. **IPO 실패**: 2022년 기업공개 추진했으나 시장 침체와 매출 요건 미달로 무산 → 추가 자금조달 경로 차단

### 4.2 외부 요인
1. **시장 역성장**: 크래프트맥주 시장 2021년 1,520억 → 2023년 752억 (반토막)
2. **편의점 채널 한계**: "4캔 1만원" 가격 천장으로 소규모 양조장 수익성 파괴
3. **소비자 트렌드 이동**: MZ세대 관심이 위스키, 하이볼, 무알코올로 분산
4. **산업 구조적 위기**: 180개 양조장이 맥주 시장 1.31%를 나누는 과당경쟁

## 5. 시장 환경

- **한국 크래프트맥주 시장**: 2025년 약 1조원 추정, 그러나 편의점 채널은 성장률 0.1%로 사실상 정체
- **글로벌 전망**: CAGR 8~11% 성장 전망 (리서치 기관별 상이)
- **경쟁사 동반 부진**: 세븐브로이(2025년 회생), 제주맥주(최대주주 2회 교체, 적자 지속)
- **대형사 위협**: 오비맥주(46.7%), 하이트진로(28.5%)의 프리미엄 라인 확대

## 7. 투자자 교훈 (Lessons Learned)

1. **수요 확인 전 대규모 설비 투자는 치명적** — 생산능력 확보보다 수익 모델 검증이 우선
2. **편의점 유통 = 매출 ≠ 수익** — 볼륨 확대가 수익성 개선으로 이어지지 않음
3. **시장 타이밍 리스크** — 2021년 투자 집행 → 2022년부터 시장 급냉
4. **단일 시장 의존 위험** — 해외 수출 등 다변화 없이 국내 시장에만 의존
5. **150억원 규모 VC 투자도 근본적 수익 모델 없이는 기업을 구할 수 없음**
