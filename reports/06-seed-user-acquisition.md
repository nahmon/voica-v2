# 시드 유저 획득 플랜 — Voica

> 작성일: 2026-04-10  
> 목표: 90일 내 첫 100명 유료 리서처/기업 고객 확보  
> 기준: B2B 메인 타깃(리서처·PM·마케터), 국내 시장 우선

## ICP 정의 (Ideal Customer Profile)

### Persona A — "시간에 쫓기는 스타트업 PM"

| 항목 | 내용 |
|------|------|
| **직함** | Product Manager, Product Owner |
| **회사 규모** | 시리즈 A~B 스타트업, 50~300명 |
| **현재 인터뷰 방식** | 직접 유저 리크루팅 → Zoom 인터뷰 → Notion 정리 (1건에 2~3주 소요) |
| **페인포인트** | 인터뷰 리크루팅·일정 조율에 시간 70% 낭비. 분석은 직감에 의존. ROI 증명 어려움. |
| **예산 결정권** | 직접 결재 또는 팀장 승인 (₩500K 이하 자율 집행) |
| **핵심 메시지** | "인터뷰 1건 세팅에 쓰는 2주를 없애드립니다" |

### Persona B — "대기업 UX 리서처"

| 항목 | 내용 |
|------|------|
| **직함** | UX Researcher, User Research Lead, CX Insight Analyst |
| **회사 규모** | 대기업/중견기업 UX팀, 1,000명+ (삼성·카카오·네이버·현대차 등) |
| **현재 인터뷰 방식** | 외부 리서치 에이전시 의뢰 (FGI 1회 ₩3,000K~5,000K), 내부 처리 시 패널 모집 2~4주 |
| **페인포인트** | 에이전시 비용 과다, 결과 납기 4~6주 대기, 인사이트 품질 편차 큼, 보고 자료 자체 제작 부담. |
| **예산 결정권** | 팀 예산 집행 (품의 필요하나 ₩1M 이하는 비교적 자유) |
| **핵심 메시지** | "FGI 비용의 1/10, 납기 48시간" |

### Persona C — "브랜드/마케팅 인사이트 담당자"

| 항목 | 내용 |
|------|------|
| **직함** | Brand Manager, Consumer Insight Manager, Marketing Strategist |
| **회사 규모** | 중대형 소비재·이커머스·금융, 200명+ |
| **현재 인터뷰 방식** | 정기 소비자 패널 조사(설문 위주) + 연 1~2회 정성 리서치. 설문은 깊이가 없고, 정성은 너무 비쌈. |
| **페인포인트** | 설문으로는 "왜?"를 알 수 없음. 정성 조사는 분기에 1번도 못 함. 빠른 캠페인 판단에 데이터 부족. |
| **예산 결정권** | 마케팅 예산 내 소비자 조사비 항목 (₩2M~5M/분기) |
| **핵심 메시지** | "설문은 'What', 보이스 인터뷰는 'Why' — 같은 예산으로 10배 깊이" |

### A. LinkedIn 콜드 메시지

```

"UX리서치" OR "사용자 조사"               → 국내 타깃
```

**필터 조건**: 대한민국 / 현직 / 연결 2촌 우선 / 팔로워 500명+ 우선

#### 메시지 템플릿

**[Template A — 고통 공감형]** (Persona A, B 대상)

```

리크루팅, 일정 조율, 녹취 정리... 정작 인사이트 뽑는 시간은 20%도 안 되더라고요.

저희 Voica는 AI가 수천 명 패널에게 보이스 인터뷰를 자동 진행하고
```

```
{직함}으로 계시면 정성 리서치 예산·일정 문제 익숙하실 것 같아서 연락드렸습니다.
```

```
지금 유저 목소리 어떻게 수집하고 계세요?
```

#### 주간 아웃리치 목표 및 예상 전환율

| 주차 | 발송 건수 | 예상 응답률 | 응답 수 | 데모 전환 | 유료 전환 |
|------|-----------|------------|---------|-----------|-----------|
| Week 1~2 | 50건/주 | 15% | 7~8명 | 3~4명 | 0~1명 |
| Week 3~8 | 100건/주 | 12% | 12명 | 5~6명 | 1~2명 |

### B. 인스타그램/TikTok 릴스 콘텐츠

#### 핵심 타깃 훅 전략

UX 리서처·PM은 **직업적 고통**에 반응한다. "공감" → "이게 해결책" 구조로 설계.  
인스타 주력(직장인 커리어 콘텐츠 소비층), TikTok은 보조(바이럴 가능성 높지만 리서처 밀도 낮음).

**계정 포지셔닝**: "Voica 공식" 계정이 아니라 **"리서처를 위한 인사이트 채널"** 포지션.  
→ 브랜드 광고로 느껴지지 않게. 팔로워가 실무 팁 얻으러 오는 계정으로 키움.

#### 콘텐츠 아이디어 10개

| # | 제목/훅 | 포맷 | 타깃 |
|---|---------|------|------|
| 1 | "유저 인터뷰 1건 세팅에 3주 걸렸습니다... 이 과정 전부 없애는 방법" | 비포/애프터 릴스 | Persona A, B |
| 2 | "FGI 500만원 쓴 리서처가 솔직히 털어놓는 것" | 고백형 브이로그 | Persona B |

| 4 | "AI가 100명을 동시에 인터뷰하면 어떤 리포트가 나올까?" | 실제 결과물 공개 | 전체 |
| 5 | "리서치 에이전시 없이 직접 하는 법 — 진짜로 가능한가?" | 튜토리얼형 | Persona B, C |

### C. X(트위터) / 쓰레드

#### 활동할 커뮤니티/계정 타깃

**X(트위터)**
- `#UXResearch` `#ProductManagement` `#리서치` 해시태그 팔로우
- 국내 PM/리서처 인플루언서 팔로우 + 댓글 참여: @toss_product, @kakao_devs 등 팔로워 많은 계정 리플라이
- 해외: @nngroup, @userinterviews, @dscout 등 리서치 도구 계정과 관련 대화 참여

**쓰레드**
- 인스타와 연동 — 릴스 콘텐츠의 텍스트 버전 배포
- UX 리서처 커뮤니티가 트위터보다 쓰레드에 더 많이 이동 중 (2025~2026 트렌드)

#### 바이럴 가능한 포스트 아이디어 5개

**Post 1 — 데이터 공개 (리트윗 유발)**
```
유저 인터뷰 1건에 평균 얼마나 걸리나요?

우리가 분석한 결과:
- 리크루팅: 5~10일
- 일정 조율: 2~3일  
- 인터뷰 진행: 0.5일
- 녹취·정리: 1~2일
- 분석·리포트: 2~3일

총 2~3주. 그런데 실제 인사이트 뽑는 시간은 2~3일.

나머지 90%는 없앨 수 있습니다.
```

**Post 2 — 공감 + 반전**
```
"유저 인터뷰 해야 하는데..."
→ 리크루팅 어디서 해?
→ 어떻게 섭외해?
→ 일정이 안 맞네
→ Zoom 링크 다시 보내줘
→ 녹취 파일 어디 있지?
→ 정리할 시간이 없어

결국 "나중에 하자"

이 사이클을 아는 PM에게 보내세요.
```

**Post 3 — 빌드 인 퍼블릭 (주간 업데이트)**
```
[Voica Week 3 업데이트]

이번 주:
- 신규 고객 3명 온보딩
- 가장 많이 받은 질문: "패널이 AI인 걸 응답자가 알아요?"
- 발견한 버그: 인터뷰 도중 패널 이탈률 패턴
- 다음 주 목표: 리포트 생성 시간 72h → 48h

질문 있으면 댓글로 — 솔직하게 답합니다.
```

**Post 4 — 업계 고통 공감형**
```
리서치 에이전시에 FGI 의뢰하면:

✓ 견적서 받는 데 3일
✓ 패널 모집 2주
✓ 진행 1일
✓ 결과 보고 2주
✓ 총 비용 ₩3,000,000~₩5,000,000

이 중에서 실제로 "인사이트"에 쓰이는 돈은 얼마일까요?
```

**Post 5 — 커뮤니티 질문 유발**
```
리서처분들께 물어봅니다.

지금까지 진행한 유저 인터뷰 중에서
가장 예상 밖의 인사이트가 나온 질문이 뭐였나요?

(저희가 AI 질문 설계에 참고하고 싶어서요 — 진짜입니다)
```

#### 빌드 인 퍼블릭(Build in Public) 전략

**적극 활용 권장.** 이유:
1. UX/PM 커뮤니티는 "도구 만드는 사람"에 호기심이 높음
2. 투명성이 신뢰로 전환 (AI 서비스는 불신이 초기 장벽)
3. 팔로워가 자연스럽게 잠재 고객 + 앰배서더가 됨

**실행 방법**: 매주 금요일 "주간 업데이트" 스레드 (수치 포함):
- 이번 주 완성된 인터뷰 건수
- 고객이 가장 많이 물어본 것
- 한 가지 실패/교훈
- 다음 주 집중할 것

### D. UX/리서치 커뮤니티 침투

#### 주요 커뮤니티 목록 및 접근 포지션

| 커뮤니티 | 채널 | 접근 방식 |
|---------|------|----------|
| **UXUI Korea** | 페이스북 그룹 (7만+) | 실무 팁 공유자로 활동 → 리포트 샘플 무료 공유 |
| **UX 한국 Slack** | Slack | 질문 답변 활동 → 6주 후 서비스 소개 가능 |
| **디자이너 톡방** | 카카오 오픈채팅 | 관찰자 → 고통 댓글에 DM |
| **PM이 사는 세상** | 페이스북 그룹 (5만+) | 인터뷰 관련 질문 글에 사례 댓글 |
| **한국 PM 커뮤니티** | 링크드인 그룹 | 아티클 공유 → 토론 유도 |
| **PRISM** (리서치 커뮤니티) | 자체 커뮤니티/뉴스레터 | 협업 제안 (공동 웨비나) |
| **스타트업 얼라이언스 Slack** | Slack | 스타트업 PM 밀집 |
| **Wanted 커뮤니티** | 원티드 인사이트 탭 | 아티클 기고 (리서치 방법론) |

#### 접근 원칙: 광고 X, 가치 제공 O

**단계별 접근**

```
Week 1~3:  관찰 + 공감
  - 커뮤니티에서 "유저 인터뷰", "리서치 힘들다", "패널 모집" 키워드 댓글에 공감
  - 직접적 서비스 언급 없음
  - 팔로우·연결 요청만

Week 4~6:  가치 제공
  - "유저 인터뷰 질문 설계 체크리스트" 무료 공유 (PDF)
  - "리서치 리포트 작성 템플릿" 무료 공유 (Notion)
  - 댓글에서 전문성 쌓기

Week 7~10: 자연스러운 소개
  - "저희가 만들고 있는 거랑 관련된 얘기인데요..." 식으로 서비스 언급
  - 직접 판매 아닌 "베타 테스터 찾습니다" 포지션
  - 베타 신청 폼 링크 공유

Week 11~12: 앰배서더 발굴
```

### E. 얼리어답터 프로그램

#### 베타 테스터 모집 방법

**랜딩 페이지 구성** (`voica.io/beta` 또는 현재 사이트 내 베타 신청 섹션):

```
헤드라인: "Voica 베타 테스터 50명 모집 — AI 보이스 인터뷰 무료 체험"
서브: FGI 대비 1/10 비용, 48시간 내 인사이트 리포트
CTA: "베타 신청하기 (무료)"
```

**신청 폼 필드** (5개 이하 — 짧을수록 전환율 높음):
1. 이름
2. 회사명 + 직함
3. 현재 유저 인터뷰를 얼마나 자주 하시나요? (월 1회 이하 / 월 1~3회 / 주 1회+)
4. 가장 불편한 점 (자유 입력, 선택)
5. 이메일

**모집 채널 우선순위**:
1. LinkedIn 아웃리치에서 응답자 → 베타 제안
2. 커뮤니티 가치 제공 후 베타 공고
3. 기존 고객사(삼성·카카오 등) 담당자에게 "팀원 추천" 요청

#### 인센티브 구조

| 구분 | 인센티브 | 조건 |
|------|---------|------|
| **베타 테스터 (50명)** | 인터뷰 3건 무료 크레딧 (₩360,000 상당) | 가입 후 1건 이상 실제 진행 + 피드백 제출 |
| **얼리어답터 (51~100번째)** | 첫 3개월 구독 50% 할인 | 결제 완료 시 즉시 적용 |
| **레퍼럴 보상** | 추천인에게 인터뷰 1건 무료 크레딧 | 추천받은 사람이 유료 결제 시 지급 |
| **앰배서더 (커뮤니티 영향력자)** | 월 구독 6개월 무료 | 후기 콘텐츠 1편 + 커뮤니티 소개 |

> **평생 할인 지양**: "얼리어답터 평생 무료" 같은 구조는 나중에 사업 모델 바꿀 때 부담. 대신 **기간 한정 할인**으로 설계.

#### 피드백 루프 설계

```
[인터뷰 완료 후 자동 이메일]
  → 3문 설문: 만족도(1~5) / 기대 대비 차이 / 다음에 또 쓸 의향

[Week 2 체크인 콜]
  → 베타 테스터 10명씩 그룹 콜 (30분, Zoom)

  → 신기능 먼저 공개 + 의견 수렴
  → 창업자가 직접 답변 (신뢰 형성)

[월간 인사이트 리포트]
  → 베타 테스터들이 Voica로 뽑은 인사이트 익명 사례 공유
  → "이런 걸 발견했습니다" → 다른 테스터들에게 영감
```

## 핵심 메시지 & 포지셔닝

### 한 문장 설명

**리서처에게**: "AI가 수천 명 패널과 보이스 인터뷰를 자동 진행하고, 48시간 안에 테마 분석 리포트를 드립니다 — FGI 비용의 1/10로."

**PM에게**: "유저 인터뷰 세팅에 쓰는 2~3주를 없애드립니다. 질문 업로드하면 AI가 알아서 진행합니다."

**마케터에게**: "설문으로는 알 수 없는 '왜?'를 보이스 인터뷰로 빠르게 — 캠페인 시작 전, 런칭 후, 언제든."

### "FGI 비용의 1/10" 메시지 활용법

FGI(포커스 그룹 인터뷰) 업계 표준 비용: **₩3,000,000~₩5,000,000 / 회 (패널 8~12명)**  
Voica 비교: **₩120,000~₩280,000 / 회 (패널 75명+)**

**활용 방법**:
1. **숫자를 구체적으로**: "FGI 1회 ₩4,000,000 vs Voica ₩120,000 — 패널은 오히려 6배 많습니다"
2. **리스크 역전**: "₩4,000,000 쓰고 인사이트 없을 리스크 vs ₩120,000으로 먼저 검증"
3. **빈도 논리**: "FGI는 분기 1회, Voica는 월 4회도 가능 — 같은 연간 예산으로"
4. **주의**: "1/10"은 패널 수가 아닌 **비용 대비** 메시지. 패널 깊이(FGI는 대화형 그룹 다이내믹스)는 다름을 투명하게 인정하되, "스케일과 속도"에서 우위 강조.

### 가장 강력한 소셜 증명 활용법

**고객사 로고 활용**  
삼성전자·카카오·네이버·토스·현대자동차·쿠팡·LG생활건강 로고는 즉각적 신뢰 형성.  
단, 각사 마케팅/PR 정책 확인 필요. 허락 없는 로고 사용 금지.

**활용 순서 (신뢰 강도 순)**:
1. 담당자 실명 후기 + 회사명 (가장 강력, 가장 어려움)
2. "○○○ 기업 UX팀 담당자" (익명 + 직함 + 회사 유형)
3. 로고만 나열 (회사 로고 사용 허가 필요)
4. "국내 대기업 7개사 사용 중" (간접 언급)

**실행 방법**:
- 온보딩 완료 후 2주 시점에 "후기 부탁 메일" 자동 발송
- 후기 작성 시 다음 인터뷰 1건 무료 크레딧 제공 (인센티브)
- LinkedIn 추천사 요청 → 프로필에 게시 + Voica 랜딩페이지 인용
