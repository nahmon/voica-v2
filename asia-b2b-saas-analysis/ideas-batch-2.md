## 아이디어 #4: 메뉴봇 (MenuBot)

- **서비스명**: 메뉴봇 (MenuBot)
- **한줄 설명**: 외식업 사장이 카카오톡으로 재고를 말하면, 그날 메뉴판과 발주 목록을 자동 생성해주는 SaaS
- **타겟 고객**: 한국 중소 외식업 자영업자 (직원 1~5명, 매장 1~3개 운영, 연매출 3억 이하)
- **핵심 문제**: 소규모 식당 사장은 매일 아침 냉장고를 직접 보고 머릿속으로 그날 메뉴를 결정한다. 식재료 낭비와 품절 사고가 반복되지만 ERP는 너무 비싸고 복잡하다. 발주도 각 식재료 업체에 전화로 하나하나 해야 해서 하루 1~2시간을 낭비한다.
- **수익 모델**:
  - 기본 플랜: 월 29,000원 (매장 1개, 메뉴 자동 생성 + 발주 초안)
  - 프로 플랜: 월 59,000원 (매장 3개, 카카오 알림톡 발주 자동 발송, 원가율 리포트)
  - 연간 결제 시 2개월 무료
- **바이브코딩 가능성**: 카카오 비즈니스 메시지 API + GPT-4o로 자연어 재고 입력을 파싱하는 핵심 로직을 Claude Code로 하루 안에 프로토타입 가능하다. UI는 단순한 대시보드 하나로 충분하며 복잡한 인프라 불필요.
- **아시아 특화 포인트**: 한국 자영업자의 주요 소통 채널은 카카오톡이다. 별도 앱 설치 없이 기존 카카오채널로 운영되므로 온보딩 마찰이 극히 낮다. 또한 한국 외식업의 식재료 공급망은 마켓컬리 for Business, 청과 도매상 등 다수 공급처가 파편화되어 있어 통합 발주 도구의 수요가 크다.

## 아이디어 #5: 계약레이더 (ContractRadar)

- **서비스명**: 계약레이더 (ContractRadar)
- **한줄 설명**: 중소기업이 거래처로부터 받은 계약서를 업로드하면, 불리한 조항과 누락된 표준 조항을 3분 안에 리포트해주는 AI 계약 검토 도구
- **타겟 고객**: 법무팀이 없는 한국 중소 제조·유통 기업 (직원 10~100명, 거래처와 연간 10건 이상 계약 체결)
- **핵심 문제**: 중소기업은 법무팀이 없어 대기업 거래처가 제시한 계약서를 거의 그대로 사인한다. 변호사 검토는 건당 30~100만원으로 비용 부담이 크고, 담당자는 어디가 문제인지조차 모른 채 서명하는 경우가 대부분이다. 손해배상 한도, 자동갱신 조항, 일방적 단가 변경권 같은 독소 조항이 나중에 분쟁의 씨앗이 된다.
- **수익 모델**:
  - 종량제: 계약서 1건 검토당 9,900원 (최초 3건 무료)
  - 팀 플랜: 월 99,000원 (월 20건, 팀원 5명)
  - 엔터프라이즈: 월 299,000원 (무제한, API 연동, 커스텀 체크리스트)
- **바이브코딩 가능성**: PDF 파싱 + GPT-4o의 문서 분석 능력만으로 핵심 기능 구현이 가능하다. 체크해야 할 조항 목록(손해배상, 지식재산권, 자동갱신 등)을 프롬프트로 정의하면 별도 ML 모델 없이 즉시 동작하는 프로토타입이 만들어진다.
- **아시아 특화 포인트**: 한국은 대기업-중소기업 간 갑을 관계가 뚜렷하고, 중소 협력사는 계약 협상력이 낮다. 일본 역시 하청 구조(下請け)가 강해 동일한 문제가 존재한다. 한국 표준계약서(공정거래위원회 양식) 대비 불일치 조항을 자동 감지하는 기능은 한국 시장에서 즉각적인 차별점이 된다.

## 아이디어 #6: 적재로그 (StackLog)

- **서비스명**: 적재로그 (StackLog)
- **한줄 설명**: 화물차 기사와 물류 담당자가 QR 스캔만으로 입출고를 기록하고, 실시간 위치와 배송 상태를 거래처와 공유할 수 있는 중소 물류사용 배송 추적 SaaS
- **타겟 고객**: 자체 배송 차량 3~30대를 운영하는 한국 중소 3PL 물류사 및 도매 유통사
- **핵심 문제**: 중소 물류사는 배송 상태를 카카오톡이나 전화로 거래처에 수동으로 알린다. 분실·오배송 발생 시 책임 소재를 증명할 기록이 없고, 거래처는 "지금 어디야?"를 하루에도 수십 번 전화로 묻는다. CJ대한통운 같은 대형 택배사 시스템은 자체 물류망을 가진 중소사에는 적용 불가능하다.
- **수익 모델**:
  - 스타터: 월 49,000원 (차량 5대, 거래처 공유 링크 무제한)
  - 비즈니스: 월 129,000원 (차량 20대, 카카오 알림톡 자동 발송, 월간 배송 리포트)
  - 플리트: 월 299,000원 (차량 무제한, 화주 포털, API 연동)
- **바이브코딩 가능성**: QR 생성은 라이브러리 한 줄, GPS 추적은 브라우저 Geolocation API로 구현 가능하다. 배송 상태 공유 링크는 단순한 read-only 페이지로 별도 앱 없이 모바일 웹으로 동작하므로, Cursor로 1주일 내 MVP 완성이 현실적이다.
- **아시아 특화 포인트**: 한국과 동남아(베트남, 인도네시아)는 자체 배송망을 가진 중소 유통사가 많고, 이들은 대형 플랫폼 물류(쿠팡 로켓, 라자다)에 편입되지 않고 독립 운영한다. 특히 한국의 식자재·주류·의약품 도매 유통은 규제상 자체 배송이 필수인 경우가 많아 이 도구의 수요가 안정적이다.
