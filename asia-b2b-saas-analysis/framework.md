# 평가 프레임워크: 아시아 B2B SaaS 시장성 평가

## 핵심 메트릭 정의

| # | 메트릭명 | 정의 | 가중치 |
|---|---------|------|--------|
| 1 | 규제·컴플라이언스 적합도 | 한국/아시아 시장의 규제 환경(개인정보보호법, 전자상거래법, 산업별 인허가 등)에 대한 제품의 적합성 및 규제가 경쟁 해자로 작용할 가능성 | 20% |
| 2 | 유통 채널 레버리지 | 카카오워크, 라인웍스, 네이버 클라우드 등 아시아 로컬 플랫폼 생태계와의 통합 가능성 및 기존 유통 채널을 통한 GTM 효율성 | 18% |
| 3 | SME-엔터프라이즈 확장 경로 | 한국 시장의 중소기업(SME) 진입 후 대기업/그룹사로 확장 가능한 구조적 경로의 명확성. 한국 특유의 대기업-협력사 수직 관계 활용 가능성 포함 | 17% |
| 4 | 현지화 부담 대비 방어력 | 언어, 회계 기준(K-IFRS), 세금 체계, 업무 문화 등 로컬라이제이션에 필요한 투자 대비 해당 현지화가 만들어내는 경쟁 진입 장벽의 비율 | 15% |
| 5 | 반복 매출 구조 안정성 | 월/연 구독 전환율, 이탈률(churn) 구조, 계약 기반 매출(한국 B2B의 연단위 계약 선호 특성 반영) 등 예측 가능한 반복 매출 확보 가능성 | 15% |
| 6 | 아시아 횡단 확장성 | 한국 시장 검증 후 일본, 동남아, 대만 등 인접 시장으로의 확장 시 제품 변경 최소화 정도 및 공통 비즈니스 로직의 재사용 가능성 | 10% |
| 7 | 기존 워크플로우 대체 난이도 | 엑셀/수기/레거시 온프레미스 시스템 등 기존 업무 방식에서 SaaS로 전환 시 조직적 저항과 전환 비용의 크기 (낮을수록 높은 점수) | 5% |

**합계: 100%**

## 5점 척도 기준 정의

### 메트릭 1: 규제·컴플라이언스 적합도 (20%)
| 점수 | 기준 |
|------|------|
| 5 | 규제가 제품의 존재 이유 자체임 (예: 전자세금계산서 의무화, ESG 공시 의무). 법적 요구사항이 곧 수요를 창출하며, 규제 준수 자체가 해외 경쟁자의 진입을 구조적으로 차단함 |
| 4 | 산업별 규제(금융 마이데이터, 의료 PACS 인증 등)를 충족해야 하며, 이를 사전 대응하는 것이 명확한 경쟁 우위. 인증 획득에 6개월 이상 소요되어 후발주자 진입이 어려움 |
| 3 | 개인정보보호법(PIPA), 클라우드 보안 인증(CSAP) 등 일반적 규제 준수가 필요하나, 대부분의 경쟁자도 충족 가능한 수준. 차별화보다는 최소 요건에 해당 |
| 2 | 규제 환경이 불확실하거나 유동적이어서 제품 설계 방향이 언제든 변경될 위험이 있음 (예: 아직 시행령이 확정되지 않은 신규 법안 의존) |
| 1 | 규제가 제품에 불리하게 작용함 (예: 데이터 국외 이전 제한으로 글로벌 클라우드 활용 불가, 특정 업종 SaaS 금지 등) 또는 규제 리스크를 전혀 평가하지 않은 상태 |

### 메트릭 2: 유통 채널 레버리지 (18%)
| 점수 | 기준 |
|------|------|
| 5 | 카카오워크/네이버웍스 등 로컬 플랫폼의 공식 마켓플레이스에 입점 가능하며, 플랫폼 API를 활용한 깊은 통합(알림, 결재, SSO)이 제품 핵심 가치를 증폭시킴. 플랫폼의 영업 채널도 활용 가능 |
| 4 | 주요 로컬 플랫폼 1~2개와 API 연동이 가능하고, 해당 플랫폼의 기존 사용자 베이스를 통해 유기적 획득이 기대됨. 또는 통신사(KT, SKT) B2B 번들링 파트너십 확보 가능 |
| 3 | 로컬 플랫폼과 기본적 연동(웹훅, 이메일 알림 수준)은 가능하나, 차별적 유통 이점은 제한적. 자체 영업 조직이 주요 GTM 채널 |
| 2 | 유통 채널이 자체 직접 영업에 전적으로 의존하며, 로컬 플랫폼 생태계와의 접점이 거의 없음. 한국 B2B 영업의 관계 기반 특성상 초기 트랙션 확보가 매우 느릴 것으로 예상 |
| 1 | 기존 유통 채널과 충돌하거나 (예: 기존 SI/리셀러 구조를 위협), 타겟 고객이 사용하는 플랫폼에서 기술적으로 통합이 불가능한 구조 |

### 메트릭 3: SME-엔터프라이즈 확장 경로 (17%)
| 점수 | 기준 |
|------|------|
| 5 | 대기업 그룹사의 협력사 관리 시스템에 내장되어, 1차/2차 협력사로 자연스럽게 하향 확산(top-down) 되거나, 반대로 협력사에서 시작해 그룹사 표준으로 상향 채택(bottom-up)되는 구조적 경로가 존재 |
| 4 | SME에서 시작하여 같은 산업 내 중견기업으로 확장하는 명확한 단계가 있음. 가격 체계가 사용량/사용자 수 기반으로 자연스러운 업셀이 가능하며, 엔터프라이즈 기능(감사 로그, 권한 관리, SLA)의 추가 개발 범위가 예측 가능 |
| 3 | SME와 엔터프라이즈 양쪽 모두에 가치를 제공하나, 각 세그먼트별 요구사항 차이가 커서 별도의 제품 버전 또는 상당한 커스터마이제이션이 필요 |
| 2 | 특정 규모의 기업에만 적합하며 확장 경로가 불분명. SME 전용이면 ARPU 한계, 엔터프라이즈 전용이면 초기 영업 주기가 6개월 이상 |
| 1 | 타겟 세그먼트가 정의되지 않았거나, 한국 시장의 기업 규모별 구매 의사결정 구조(품의서, 내부 결재 등)를 고려하지 않은 상태 |

### 메트릭 4: 현지화 부담 대비 방어력 (15%)
| 점수 | 기준 |
|------|------|
| 5 | 현지화 투자가 곧 핵심 제품 가치임 (예: 한국 회계 기준 자동 처리, 한국어 자연어 처리 기반 기능). 글로벌 경쟁자가 동일 수준 현지화에 2년 이상 소요될 것으로 예상되며, 현지화된 데이터가 축적될수록 방어력 증가 |
| 4 | 업무 프로세스 현지화(한국식 결재 라인, 직급 체계, 근태 관리 규정 등)가 필요하고, 이를 구현한 것 자체가 유의미한 차별화. 현지화 투자 대비 방어력 비율이 높음 |
| 3 | UI/UX 한국어화 및 기본적 로케일 처리(날짜, 통화, 주소 체계) 수준의 현지화가 필요. 경쟁자도 3~6개월 내 따라올 수 있는 수준 |
| 2 | 현지화 범위가 넓고 비용이 높으나(다국어, 다통화, 다법률 체계), 완료 후에도 글로벌 SaaS 대비 차별화가 크지 않음. 투자 대비 방어력이 낮음 |
| 1 | 현지화가 거의 불필요한 제품(영문 글로벌 제품으로 충분)이어서 글로벌 SaaS 대비 로컬 차별화 요소가 없거나, 현지화 비용이 시장 규모 대비 과도함 |

### 메트릭 5: 반복 매출 구조 안정성 (15%)
| 점수 | 기준 |
|------|------|
| 5 | 연간 계약 기반이며, 고객사의 핵심 업무 프로세스에 임베디드되어 전환 비용이 매우 높음. 월 이탈률 1% 미만 예상. 사용량 증가에 따른 자연 확장 매출(Net Revenue Retention 120%+) 구조 |
| 4 | 월/연 구독 모델이 명확하며, 한국 B2B 고객의 연단위 계약 선호에 부합. 최소 약정 기간 설정 가능. 이탈률 월 2% 이내 예상. 부가 기능 업셀 경로 존재 |
| 3 | 구독 모델이나, 고객이 언제든 해지 가능하고 전환 비용이 낮음. 이탈률 월 3~5% 예상. 또는 한국 시장의 SI 프로젝트성 계약 요구(일시불 라이선스)와 구독 모델 간 긴장이 존재 |
| 2 | 매출의 상당 부분이 초기 구축비/컨설팅에 의존하며, 반복 매출 비율이 전체의 50% 미만. 또는 사용량 기반 과금이나 사용 패턴이 불규칙하여 매출 예측이 어려움 |
| 1 | 일회성 거래 또는 프로젝트 기반 매출 구조. 구독 전환 가능성이 불분명하거나, 무료 대안(오픈소스, 정부 지원 시스템)이 존재하여 유료 전환이 구조적으로 어려움 |

### 메트릭 6: 아시아 횡단 확장성 (10%)
| 점수 | 기준 |
|------|------|
| 5 | 한국에서 검증된 제품이 일본·동남아 시장에 최소 변경(언어, 통화 수준)으로 진출 가능. 비즈니스 로직의 80% 이상이 국가 간 공통. 이미 진출 대상국에 유사 수요가 검증됨 (예: 전자상거래 물류, 제조업 품질관리) |
| 4 | 핵심 엔진은 공통이나, 국가별 규제/세무/회계 모듈 추가 개발이 필요. 일본 또는 동남아 1개국으로 확장 시 추가 개발 비용이 초기 개발의 30% 이내 |
| 3 | 2~3개국 확장이 가능하나, 국가별 커스터마이제이션 범위가 넓음 (별도 파트너/현지 팀 필요). 확장 시 초기 개발의 50% 수준 추가 투자 예상 |
| 2 | 한국 시장 특화도가 높아 타국 진출 시 사실상 재개발에 가까움. 또는 타겟 시장의 규모가 한국보다 작아 확장의 경제성이 낮음 |
| 1 | 한국 내수 전용 제품 (예: 한국 특정 법률/제도에만 적용). 아시아 타국 확장이 구조적으로 불가능하거나, 각국에 이미 강력한 로컬 경쟁자가 존재 |

### 메트릭 7: 기존 워크플로우 대체 난이도 (5%)
| 점수 | 기준 |
|------|------|
| 5 | 기존에 솔루션이 없던 신규 워크플로우를 생성하거나, 현재 엑셀/수작업으로 처리하는 업무를 자동화. 대체가 아닌 신규 도입이므로 조직적 저항이 최소 |
| 4 | 기존 엑셀/이메일 기반 프로세스를 대체하며, 데이터 마이그레이션 부담이 적고 병행 운영이 가능. 현업 담당자가 즉시 가치를 체감할 수 있는 구조 |
| 3 | 기존 레거시 시스템(온프레미스 ERP, 자체 개발 시스템)과 병행 또는 연동이 필요. IT 부서 협조 필수이나, API 연동 등으로 점진적 전환 가능 |
| 2 | 전사적 시스템 교체가 필요하며, 데이터 마이그레이션 및 사용자 재교육에 3개월 이상 소요 예상. 의사결정권자 다수의 합의가 필요 |
| 1 | 핵심 레거시 시스템(기간계 ERP, MES 등)을 완전 대체해야 하며, 실패 시 업무 중단 리스크. 한국 대기업의 SI 벤더 종속 구조상 전환이 거의 불가능 |

## 총점 산출 방법

각 SaaS 아이디어에 대해 7개 메트릭별로 1~5점을 부여한 후, 가중 합산하여 총점을 산출합니다.

**총점 = Σ (메트릭 점수 × 가중치)**

| 총점 범위 | 등급 | 해석 |
|-----------|------|------|
| 4.0 ~ 5.0 | A | 즉시 깊은 검증(고객 인터뷰, MVP) 진행 권장 |
| 3.0 ~ 3.9 | B | 특정 메트릭 보완 후 재평가. 약점 메트릭이 구조적인지 확인 필요 |
| 2.0 ~ 2.9 | C | 피봇 또는 시장 재정의 필요. 현재 형태로는 투자 부적합 |
| 1.0 ~ 1.9 | D | 근본적 재검토 필요. 해당 시장/제품 조합 포기 권장 |
