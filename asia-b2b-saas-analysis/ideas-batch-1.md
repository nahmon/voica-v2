## 아이디어 #1: 근태왕 (勤怠王)

- **서비스명**: 근태왕 (Geuntaewang)
- **한줄 설명**: 포괄임금제 환경에서도 법정 근로시간·연장수당을 자동으로 계산하고 노무 리스크를 사전에 경보해주는 중소기업 전용 근태·급여 보조 SaaS
- **타겟 고객**: 한국 50인 미만 제조·서비스 중소기업의 경리·총무 담당자 (노무사를 별도로 고용하기 어려운 사업장)
- **핵심 문제**: 2024년 중대재해처벌법·근로기준법 연속 개정으로 연장근로 한도, 휴가 정산, 포괄임금 계약의 적법성 기준이 복잡해졌다. 중소기업 경리 담당자는 엑셀로 출퇴근을 관리하다가 고용노동부 감독 시 수백만 원 과태료를 맞는 사례가 빈번하다. 기존 대형 인사관리 시스템(더존, 그룹웨어)은 구축 비용이 월 30~100만 원 이상으로 소규모 사업장엔 진입 장벽이 높다.
- **수익 모델**: 직원 1인당 월 3,000원 구독 (10인 사업장 = 월 3만 원). 노무 리스크 리포트 월 1회 자동 발송 포함. 노무사 연결 중개 수수료(건당 3만 원) 추가 수익.
- **바이브코딩 가능성**: 근태 데이터 입력 → 법정 계산식 적용 → 경보 발송의 선형 로직으로, AI 코딩 툴로 Next.js + Supabase 스택에서 2~3주 내 MVP 구현 가능. 복잡한 ML이나 실시간 처리 불필요.
- **아시아 특화 포인트**: 포괄임금제는 한국 특유의 제도로 서구 HR SaaS(Rippling, Gusto 등)가 지원하지 않는다. 일본의 '잔업 제로' 규제(働き方改革), 대만의 勞基法 개정도 동일한 니즈를 만들어 아시아 전역 확장 시나리오가 명확하다.

## 아이디어 #2: 세금계산서 자동분류기 (TaxFlow AI)

- **서비스명**: TaxFlow AI (택스플로우)
- **한줄 설명**: 카카오톡·이메일·홈택스로 수신된 전자세금계산서를 자동으로 비용 계정과목에 분류하고, 부가세 신고용 엑셀·장부를 원클릭으로 생성해주는 소규모 법인·프리랜서 전용 SaaS
- **타겟 고객**: 한국 연매출 10억 원 미만 소규모 법인 및 개인사업자 중 세무 기장을 직접 처리하거나 세무사 비용을 줄이고 싶은 대표·경리 담당자
- **핵심 문제**: 국세청 홈택스에서 전자세금계산서를 확인할 수 있지만, 이를 회계 장부의 계정과목(광고비, 복리후생비, 외주용역비 등)으로 분류하는 작업은 여전히 수작업이다. 매분기 부가세 신고 시즌마다 수백 건의 계산서를 엑셀에 옮겨 붙이는 데 사장 또는 경리가 2~3일을 소모한다. 세무사 월 기장료(15~30만 원)는 영세 사업자엔 부담이 크다.
- **수익 모델**: 월 9,900원(기본, 계산서 100건/월) / 월 24,900원(스탠다드, 500건/월). 홈택스 API 연동 자동화 설정 시 초기 셋업 피 19,000원.
- **바이브코딩 가능성**: 홈택스 공개 API + GPT API를 이용한 계정과목 자동 분류 로직이 핵심으로, Claude나 GPT를 function calling으로 연결하면 분류 엔진을 별도 ML 없이 구현 가능. 프론트엔드는 단순 대시보드로 AI 코딩 툴로 1~2주 안에 MVP 제작 가능.
- **아시아 특화 포인트**: 전자세금계산서 의무 발행 제도는 한국이 세계에서 가장 촘촘하게 운영 중이며, 일본의 インボイス制度(2023 도입)도 동일 문제를 만들었다. 서구 회계 SaaS(QuickBooks, Xero)는 한국·일본의 세금계산서 체계를 지원하지 않아 로컬 플레이어에 절대적으로 유리한 시장.

## 아이디어 #3: 영업노트 (YeongeopNote)

- **서비스명**: 영업노트
- **한줄 설명**: 한국 B2B 영업 특유의 '관계 영업' 방식에 맞춰, 명함·카카오톡 대화·방문 메모를 자동으로 연락처 CRM에 정리하고 다음 액션(식사 제안, 추석 선물 발송 타이밍 등)을 AI가 제안해주는 중소기업 영업팀 전용 CRM
- **타겟 고객**: 한국 B2B 중소기업의 영업·BD 담당자 (5~30인 영업팀), 특히 건설자재, 산업재, 식자재 유통처럼 담당자 관계가 수주에 결정적인 업종
- **핵심 문제**: Salesforce·HubSpot은 한국 관계 영업 문화(명절 선물, 식사 접대, 담당자 이직 추적)를 반영하지 않으며 UI가 복잡해 현장 영업사원들이 입력을 꺼린다. 결국 영업 데이터는 개인 카카오톡과 명함 케이스에 분산되어 퇴사 시 고객 정보가 통째로 사라진다. 이직률이 높은 한국 영업 조직에서 이는 반복되는 구조적 손실이다.
- **수익 모델**: 영업사원 1인당 월 15,000원 구독. 5인 팀 기준 월 75,000원. 카카오톡 비즈니스 메시지 발송 연동(건당 과금) 부가 수익.
- **바이브코딩 가능성**: 명함 OCR(Google Vision API), 카카오톡 내보내기 파싱, LLM 기반 다음 액션 제안이라는 3개의 독립 모듈을 API 조합으로 구현 가능. 복잡한 실시간 동기화나 엔터프라이즈 SSO 없이 웹앱+모바일 웹으로 AI 코딩 툴 활용 시 3~4주 MVP 가능.
- **아시아 특화 포인트**: '관계 영업(Relationship Sales)'은 한국·일본·대만·동남아 B2B 시장의 공통 특성으로, 인맥 관리와 명절·기념일 챙기기가 수주 성패를 좌우한다. 서구 CRM은 이 문화적 맥락을 무시하고 딜 파이프라인 중심으로 설계되어 있어, 아시아 로컬 CRM이 들어설 틈이 명확히 존재한다.
